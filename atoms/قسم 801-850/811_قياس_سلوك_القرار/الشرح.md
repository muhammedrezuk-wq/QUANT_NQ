# 811 — قياس سلوك القرار

**ما هي:** مسطرة. تقرأ بطاقة الدرجة الخارجة من `453` وتقيس **حركتها** — لا أكثر.
**ما ليست:** ليست فلترًا ولا بوّابة ولا مشاركًا في القرار. **لا تُخرج حكمًا ولا عتبة ولا رقمًا يدخل مسار القرار.**

**ولماذا رقمها في كتلة القياس لا في كتلة القرار:** كي لا يظنّها قارئٌ يومًا جزءًا ممّا تراقبه.

---

## لماذا وُجدت

بأمر المالك ٢٠٢٦-٠٨-٢٥: قبل إنزال أيّ معايرة جديدة، **يلزم خطّ أساس**.
بلا رقمٍ **قبل**، لا يمكن الحكم على رقمٍ **بعد** — ويصير الحكم انطباعًا لا قياسًا.

**والفخّ الذي سمّاه المالك بنفسه:** انخفاض القفز إلى الصفر **لأنّ النظام سكت** فشلٌ لا نجاح.
لذلك كل رقم قفز هنا يسير **بجانب** عدد الإشارات والجاهزة والمحايدة — فلا يُقرأ الهدوء نجاحًا.

---

## ما تسمعه

```
decision.scored.state        من 453 — بطاقة الدرجة
```

وتقرأ منها خمسة أرقام بأسمائها الحيّة:
`direction_value` · `strength_value` · `confidence_value` · `net` · `participation`.
**وأيّ حقلٍ غائبٍ منها يُرفض ويُعدّ بسببه** — لا يُخترع ولا يُصفَّر.

## ما تنشره

```
decision.behaviour.telemetry
```

**لكل دورة، ولكل (حساب × وسيط × رمز) على حدة:**

| البند | المحتوى |
|---|---|
| الحركة | لكل واحد من الخمسة: **السابق · الحاليّ · الفرق** |
| القفز | إحصاء نافذة متدحرجة (٥١٢ دورة) للاتّجاه والقوّة والثقة: العدد · المتوسّط · الوسيط · ٩٠ · ٩٥ · الأقصى |
| الانتقال | اسم الانتقال (شراء←بيع · بيع←شراء · شراء←حياد · بيع←حياد · حياد←شراء · حياد←بيع) |
| الانعكاس | تصنيفه: **مباشر** `DIRECT_REVERSAL` أم **بعد حياد** `REVERSAL_AFTER_NEUTRAL` |
| الثبات | طول البقاء في الجهة نفسها: الوسيط · ٢٥ · ٧٥ · الأقصى (نافذة ٢٥٦) |
| العدّ | القرارات · الإشارات · الجاهزة · المحايدة · الانعكاسات |
| المعدّلات | لكل دقيقة — للخمسة أعلاه |

## الوقت — ولا ساعة تُقرأ

`811` **ليست من الثلاث المالكات للساعة** (`3` · `806` · `608`)، ولا تقرأ ساعة إطلاقًا.
كل معدّل هنا محسوب من **ختم السوق الموجود على البطاقة نفسها**
(`source_timestamp` ثمّ `period_start` ثمّ `timestamp`)، ومن الفرق بين أوّل ختم وآخره.
**وحين لا يُقاس زمنٌ منقضٍ، تكون المعدّلات `null` معلَنة — لا صفرًا كاذبًا.**

## تصنيف الانعكاس — بالضبط

```
كانت جهة  ←  صارت الجهة المقابلة مباشرةً        ⇒  DIRECT_REVERSAL
كانت جهة  ←  حياد  ←  الجهة المقابلة            ⇒  REVERSAL_AFTER_NEUTRAL
```

والفرق بينهما هو **جوهر السؤال**: هل قلّت الانقلابات المباشرة فعلًا، أم أنّها مرّت بحياد وحسب؟

---

## كيف أتأكّد أنّ الذرّة شغّالة؟

```
١  شغّل النظام، وانتظر حتى يُخرج 453 بطاقتين على الأقلّ لرمزٍ واحد
٢  اقرأ صحّة 811:   seen > 0   و   emitted > 0   و   scopes > 0
٣  افتح تفاصيل صحّتها: لكل رمز كتاب فيه jump_stats و run_stats و counts
٤  الدورة الأولى لكل رمز: كل الفروق null — لا سابق لها، وهذا صدق لا عطل
٥  الدورة الثانية فصاعدًا: الفروق أرقام، و jump_stats.count يتقدّم
٦  إن بقيت المعدّلات null فالسبب أنّ الختم لم يتقدّم — تُقرأ elapsed_market_s
```

**والحكم:** لا تُعدّ ناجحة بمرور الاختبار وحده — تُعدّ ناجحة حين تُخرج **أرقامًا فعليّة أثناء التشغيل**.
