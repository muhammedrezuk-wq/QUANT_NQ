`governance/ui/src/sections/Mexc.tsx`

`btn` معرَّفة **دالّة** (سطر 15):
```tsx
const btn = (extra?: React.CSSProperties): React.CSSProperties => ({ ... })
```
وكل الاستعمالات تستدعيها صحيحًا `style={btn(...)}` — **إلا سطرين نسيا الأقواس**،
فمُرِّرت **الدالّة نفسها** إلى `style` ⇒ React ينفجر ويسحب التطبيق كلّه.
