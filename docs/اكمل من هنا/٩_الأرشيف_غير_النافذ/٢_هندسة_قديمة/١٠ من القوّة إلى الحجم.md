# من القوّة إلى الحجم — التعرّض والتحوّط والفرق

## هـ · من القوّة إلى الحجم

```
capacity = min(max_target_volume, R_B ÷ (price × stop_distance_frac × vpu))
```

**جدول التعرّض والتحوّط النافذ:**

| `S` | التعرّض `E(S)` | التحوّط `H(S)` | الصافي ÷ السعة |
|---:|---:|---:|---:|
| `< 0.20` | 0٪ | **100٪** | **0٪ — والإجماليّ محفوظ** |
| `0.20 – <0.40` | 10٪ | 70٪ | 3٪ |
| `0.40 – <0.60` | 25٪ | 40٪ | 15٪ |
| `≥ 0.60` | 50٪ | 20٪ | 40٪ |

**السلم أربع درجات لا خامسة لها** (`bands` و`hedge_bands` في مانيفست 581 v3.3.0) —
لا درجة `≥ 0.90` في الكود، والتعرّض يقف عند 50٪ مهما علت القوّة.

**وهستيريسيس حسم الاتّجاه الممسوك:** الدخول عند `S ≥ 0.20` والخروج عند `S ≤ 0.15`
(`s_enter`/`s_exit` في 581) — كي لا يرتجف الاتّجاه حول عتبة واحدة.

```
G   = capacity × E(S)
N   = G × dir × (1 − H(S))
Buy = (G + N) ÷ 2
Sell= (G − N) ÷ 2
```

**المبدأ:** كلّما زادت القوّة قلّ التحوّط. **التحوّط يخفّف اتّجاهًا ضعيفًا ولا يلغي
اتّجاهًا قويًّا.**

**وعند `S < 0.20`: التعرّض صفر يعني صفر صافٍ اتّجاهيّ — لا صفر مركز.** الإجماليّ يُحفظ
من المركز السابق.

## و · الفرق فقط

```
base_target   = min(capacity × E(S), gross_cap)
              وعند ضعف S عن سابقتها: لا يتجاوز previous_gross
              وعند E(S) = 0:        يُحفظ current_gross  ← NEUTRAL_KEEP_GROSS
              (تحديث ٢٦-٠٨ — عيار المخاطرة، عقد المحورين v1.1 §3 مختوم NQ:)
D             = RISK_DIAL ÷ 100          ← بدؤه 100 = سلوك اليوم حرفيًّا
target_gross  = current_gross
              + min(max(0, base_target − current_gross), capacity × E(S) × D)
              − max(0, current_gross − base_target)     ← الخفض يتبع التحليل وحده
              (وميزانية الدايل: dial_add_budget ≤ 0 ⇒ لا زيادة — ورقة ١٧ §3)
target_buy    = max(0, (target_gross + target_net) ÷ 2)
target_sell   = max(0, (target_gross − target_net) ÷ 2)
delta_buy     = clip(target_buy  − current_buy,  ∓ max_step_volume)
delta_sell    = clip(target_sell − current_sell, ∓ max_step_volume)
```

**لا يُرسَل المركز المطلوب — يُرسَل الفرق عنه.** والـ`gross` يتبع درجة القوّة نازلًا
وصاعدًا، ولا يُحفظ كاملًا إلا عند `E = 0` — والتحوّط يتولّد تلقائيًّا عند الضعف
لأنّ `H(S)` يرتفع كلّما هبطت `S`.
