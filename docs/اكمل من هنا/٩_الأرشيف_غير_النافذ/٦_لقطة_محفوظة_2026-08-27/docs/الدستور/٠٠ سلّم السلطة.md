# ١ · سلّم السلطة

**عند أي تعارض، يُحسم بهذا الترتيب ولا يُتجاوز:**

```
١ · المالك                     كلمته نافذة، وتُنفَّذ بعد اعتراض واحد إن لزم
٢ · أحدث ورقة مختومة           تنسخ ما قبلها في موضع التعارض
٣ · الورقة الأقدم              تبقى سارية فيما لم يُنسخ
٤ · الكود الحيّ                هو الحقيقة حين تتعارض مع ورقة غير مختومة
٥ · اجتهاد المنفّذ             آخر المصادر، ولا يعلو على شيء مما فوقه
```

**والقاعدة المقابلة، وهي مدفوعة الثمن:**

> **الكود هو الحقيقة والورق يكذب.**
> عند تعارض الكود مع ورقة، **الورقة هي الكاذبة** — تُصحَّح أو تُؤرشَف في اللحظة نفسها.
> ورقة تناقض الواقع تجعل الشغل الصادق يبدو كذبًا.
