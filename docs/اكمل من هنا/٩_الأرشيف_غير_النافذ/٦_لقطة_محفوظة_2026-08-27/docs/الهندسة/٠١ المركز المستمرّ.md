# ٢ · الفكرة التي يقوم عليها كل شيء — المركز المستمرّ

**الوحدة ليست صفقة. الوحدة `(حساب × أصل)`.**

النظام لا يفتح صفقة ويغلقها. **يحمل للأصل مركزًا مستمرًّا** ويحرّك تعرّضه صعودًا
وهبوطًا مع قوّة الاتّجاه.

```
state.direction    = BUY | NEUTRAL | SELL
state.buy_volume   = مجموع أرجل الشراء الفعليّة
state.sell_volume  = مجموع أرجل البيع الفعليّة
state.net_volume   = buy − sell
state.gross_volume = buy + sell
state.R_B          = ميزانيّة المخاطرة بالدولار لهذا الأصل وحده
state.u            = التعرّض للخسارة ÷ R_B
state.K, state.X   = الربح المُبقى، والمخرَج فعليًّا
state.stop_state   = READY | HEDGED | FROZEN
```

## أربع حالات لا خامسة لها

| الحالة | المعنى |
|---|---|
| **بداية محايدة** | شراء وبيع بحجم متساوٍ — الصافي صفر، والمركز موجود |
| **بناء اتّجاه** | تقوية الجهة الموافقة وتقليص المضادّة |
| **ضعف الاتّجاه** | التحوّط يتولّد **من المعادلة نفسها** بلا أمر منفصل |
| **الانعكاس** | **إعادة توزيع لا إغلاق** — الإجماليّ محفوظ |

**التحوّط أداة انتقال، لا اتّجاه رابع.** ويجوز وجود شراء وبيع معًا.
**ولا يوجد في النظام أمر `CLOSE_ALL` أصلًا.**
