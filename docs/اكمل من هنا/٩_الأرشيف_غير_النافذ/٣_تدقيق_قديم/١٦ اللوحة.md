# ٥ · اللوحة

## مسار البيانات — كل شيء يصلها

```python
# core/api/app.py
event_bus.subscribe_all(_broadcast, subscriber="api.websocket", isolate_payload=False)
```

اللوحة تفتح **وصلة واحدة**، والنواة تبثّ عليها **كل حدث خام**.
⇒ **مسألة «حدث بلا مشترِك معلَن» لا تمسّ اللوحة إطلاقًا.**

## الأحداث بلا مشترِك معلَن — كانت سبعة تُعرض وثلاثة تضيع، وأُغلقت

```
يُعرض (٧)          analysis.fast.state · analysis.slow.state · tilt.state
                   system.commands.state · risk.unified.state · audit.trail.state
                   market_data.state

كانت تضيع (٣)      tools.device_resources.state   ← موارد الجهاز
                   telemetry.carrier.state        ← حالة ناقل التلمترية
                   time.clock.quality.state       ← جودة الساعة
```

**(تحديث ٢٥-٠٨: أُغلقت — الأحداث الثلاثة صار لها شريط «الإنذار المبكّر» فوق كل شيء
في `governance/ui/src/components/EarlyWarning.tsx:8-12` بأسمائها العربيّة، ومن لم يصل قطّ
يُعلَن «لم يصل بعد».)** ⇒ **الإنذار المبكر لم يعد أعمى.**

## شاشة القياس — مقطوعة من طرف اللوحة وحده

```
820 ينشر measurement.health.state + measurement.latency.state   (atom.py:167 و175 — والمانيفست يعلنهما)
البحث عن "measurement." في واجهة اللوحة  →  صفر نتيجة
```

**(تحديث ٢٥-٠٨: طرف المصدر وُصل — `820` صار ينشر الحدثين فعلًا. الباقي طرف واحد:
اللوحة ما زالت بلا سطر يعرضهما.)**

## 🟠 خطر مقيس في مسار اللوحة

```python
# core/api/app.py
queue = _DroppingQueue(maxsize=500)
```

**طابور وصلة اللوحة خمسمئة رسالة وسياسته الإسقاط عند الامتلاء**، والبثّ بالمئات في
الدقيقة. **ولم يُقس كم رسالة تُسقَط، ولا إن كانت تسقط أحداث حرجة.**
