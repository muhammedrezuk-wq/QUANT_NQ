## ١ · سجلّ المُعامِلات — الطبقة الأم

**الملف:** `shared/parameter_registry.py` · **القاعدة:** `var/store/analysis_settings.db` (تحويلها بمتغير البيئة `QUANT_ANALYSIS_SETTINGS_DB`).

**الجدول `parameters`** — المفتاح `(name, scope)`:
```text
name · scope · value(REAL) · source(UNSET/OWNER/BACKTEST/VENDOR) ·
status(APPROVED/UNAPPROVED) · version · effective_from · approved_by ·
approved_at · governs · declared_at
```
وجدول تدقيق `parameters_audit` بفهرس فريد `(command_id, name, scope)` — الاعتماد المكرر بنفس الأمر يعيد نتيجته الأولى (idempotent).

**القوانين:**
1. الإعلان `INSERT OR IGNORE` — إعادة التشغيل لا تُرجع معتمَدًا إلى UNAPPROVED.
2. `approve()` يرفض `source=UNSET` ويشترط هوية (`approved_by` + `command_id`).
3. **القراءة الحية عبر بصمة الملف** (`approved_value`): stat كل ≤2ث لا استعلامًا بالمسار الساخن — اعتماد يُكتب من عملية الحوكمة يصل عملية النواة خلال ثوانٍ **بلا إقلاع** (حلّ «ما بتتحمل إلا عالبارد» المقيس ٢٥-٠٨).
4. غير المعتمد لا يغيّر سلوكًا: قيمة المانيفست/الكود هي السارية (السقوط الصادق).

## ٢ · عيارات القرار — طبقة اللوحة

**الملف:** `shared/decision_dials.py` — قاموس `DIALS`: لكل عيار `{value=الساري اليوم، atom=الذرة المالكة، key، governs، display(percent/raw/integer)، bounds، [scoped]}`.

**مسار التعديل الوحيد (لا استثناء):**
```text
اللوحة (الإعدادات › عيارات القرار — تأكيد بخطوتين)
  → /gov/command action=decision_setting {name, value[, account_id, symbol]}
  → جسر الأوامر → ذرّة 901 (تتحقق: الاسم في DIALS + القيمة داخل bounds؛
     تمرّر الحمولة كاملة + operator/command_id/command_requested_at)
  → تنشر decision.settings.command
  → الذرّة المالكة (spec["atom"]) تنادي apply_command:
     قصّ للحدود → [نطاق (حساب␟رمز) للمعلَن scoped فقط — غيره يتجاهل
     حقلي النطاق عمدًا كي لا يولد صف لا يقرؤه محرّكه] → registry.approve
  → تنشر decision.settings.state {atom, name, value, version[, scope]}
  → اللوحة تعيد الجلب من /gov/parameters (خادم الحوكمة :8090)
```
**القراءة في الذرّات:** `effective_value(name, قيمة_المانيفست)` — المعتمد يعلو، وإلا المانيفست.

## ٣ · عيار المخاطرة `RISK_DIAL` — بوابة نمو التعرض

**العقد الأم:** «ورقة المحورين v1.1» §3 (مختوم NQ) · **المالك:** 581 v3.4.0 · **البدء:** 100 = سلوك اليوم حرفيًّا · **موضعه الوحيد:** 581 (لا بعد Room ولا Size ولا أي بوابة لاحقة).

**المعادلة (في `shared/position_delta_recompute.py`، الفرع الاتجاهي):**
```text
D = RISK_DIAL/100
base_target      = min(capacity_full × E(S), gross_cap)   [+ سقّاطة القوة الهابطة]
increase         = max(0, base_target − current_gross)
allowed_increase = min(increase, capacity_full × E(S) × D)
decrease         = max(0, current_gross − base_target)     # الخفض يتبع التحليل وحده
gross_target     = current_gross + allowed_increase − decrease
```
**المحاسبة المنشورة مع كل هدف** (`perpetual.target.state`، يسجّلها 707 صف `TARGET_STATE`):
```text
consumed_budget = max(u_float, u_realized) × R_B     # من حقلَي 518 المنفصلين
remaining_RB = R_B − consumed_budget
dial_add_budget = R_B × D − consumed_budget          # ≤ 0 ⇒ allowed_increase = 0
remaining_add_budget = max(0, dial_add_budget)
```
**الثوابت:** دايل 0 لا يصفّي · الحياد NEUTRAL_KEEP لا يُمسّ · D لا يدخل E(S) ولا gross_cap ولا R_B. **العرض:** بطاقة الهدف بصفحة «التنفيذ». **الفحوص:** `atoms/581_محرك_فرق_المركز/tests/test_risk_dial.py` (حالات القبول المختومة §3-ج).

## ٤ · مفتاح سرعة التحليل `ANALYSIS_SPEED` — شخصية الزمن

**العقد الأم:** «ورقة المالك — معايير سرعة التحليل v1.0» + ملحقها الشفهي · **المالك:** 150 v2.8.0 · **البدء:** 50.00 = **نقطة التطابق** (كل نافذة تساوي قيمتها اليومية) · **معلَن `scoped`**: قيمة لكل (حساب␟رمز) تعلو العامة.

**الاشتقاق (`shared/analysis_speed.py`):**
```text
speed_value(حساب, رمز): (حساب␟رمز) المعتمد ← العام المعتمد ← 50.00
speed_factor(speed) = clamp(50/speed, ×0.2, ×5.0)    # 100→نصف النوافذ · 25→ضعفها
window(أساس, معامل, أرضية) = clamp(round(أساس×معامل), أرضية, 63)
```

**نقطتا الحقن:**
1. **المحرك التكّي المشترك** (`shared/live_analysis.py._analyze` — مسار الخمسة عشر محللًا الحي): النافذة الرئيسة 12 (أرضية 4) · الجلسة 32 (8) · الطويلة 24 (6) · قاسم كفاية العينة 24 (6) · السقف 63 = ذاكرة المراكم. كل حدث تحليل يحمل `analysis_speed`.
2. **نوافذ الشموع** (خط المحللين 151–165 v2.4.0 — عقد «الخط بإصدار واحد» في `tests/test_analysis_live_independence.py`): الذرّات ذوات النوافذ المعلنة تشتق عند **كل شمعة** بدالة محلية موحّدة `_speed_window(أساس, رمز, حساب, أرضية)` سقفها الأساس×5، ومخازنها `deque(maxlen=الأساس×5)`:
```text
151 slope_lookback 5 (أرضية 2) · 152 roc 10(2)/impulse 14(3)/persistence 10(3)
153 atr 14(3)/baseline 50(5)/stddev 20(5) · 154/155 baseline 50(5)
162/163/164 baseline 20(5)
```

**غير المشمول (معلَن):** `window_size=20` بذرّات الإحصاء 3xx · `tick_window=32` بالنماذج 352–356 والاستراتيجيات 404–412 · فترات EMA في 151 (تراكمية — تبديلها يحتاج إعادة بذر معلنة) · آفاق الطزاجة المعتمدة فرديًّا تبقى مثبَّتة (STALE_AFTER_S=10.01).

**الفصل عن المخاطر — مثبت بفحص دائم لا وعد:** `tests/test_analysis_speed.py::test_risk_files_never_read_speed` يجزم أن 581/508/516/518/584/552 ومعادلة الهدف لا تقرأ السرعة (grep صفر).

## ٨ · قوانين المنظومة (المدفوع ثمنها)
1. **نقطة التطابق إلزامية لأي مفتاح جديد**: يولد بقيمةٍ تعيد أرقام اليوم حرفيًّا — بلا قفزة خفية، وكل ابتعاد قرار مالك مقيس.
2. **التثبيت الفردي يعلو المفتاح**: عيار اعتمده المالك بيده لا يتبع المقبض الكبير حتى يعيد اعتماده.
3. **النطاق للمعلَن scoped فقط** — منع «النمط النائم» (صف نطاق بلا قارئ).
4. **أسطول الفحوص معزول عن السجل الحي** (`conftest.py` الجذري يحوّل `QUANT_ANALYSIS_SETTINGS_DB` لسجل مؤقت): اعتماد المالك للنظام الحي وحده، والفحوص على نقاط التطابق دائمًا.
5. **`shared/` لا يُحمَّل ساخنًا** (إعادة إقلاع لأي تعديل كود فيه) — أما **قيمة العيار فتصل حية دائمًا**. الذرّات وحدها تتبدل ساخنة.
6. **وصفة إعادة الإقلاع:** `غرفة القيادة.bat --stop` ثم قتل توأمي `governance\app.py` المتبقيين (يمسكان قفل 8099) ثم الإطلاق — وإلا مات الإطلاق صامتًا.

## ٩ · حلقة العقل — التشخيص والمعايرة الذاتية (كلمة المالك «هاد بدي ياه» ٢٦-٠٨)

**المبدأ:** المفاتيح الثلاثة التي طلبها هي **الموجودة أصلًا** — المشاهدة دائمة بلا زر · المعايرة = قاطع التكيف 860 (زر المالك عبر 901 `adaptation_switch`؛ مقطوع = وضع المشاهدة) · التنفيذ = بوابة 552/575 المستقلة تمامًا.

**اليومية دائمة القرص:** `var/store/ai_journal_870.db` — لكل تجربة الفرضية والقياس القبلي/البعدي والقرار والحالة («مسجل + قابل للمقارنة + قابل للرجوع»). حالته تُنشر `ai.brain.state` وبطاقته بتبويب «التشخيص».
