# ٤ · ختم `NQ` — لا تنفيذ بلا الرمز

**حكم ٢٠٢٦-٠٨-٢٠، نافذ على كل ما يمسّ الكود:**

```
«موافق» · «تمام» · «أختم» · «ماشي»        ←  ليست ختمًا
كلمة  NQ  صريحة                            ←  هي الختم الوحيد
```

**ما لا يحتاج ختمًا:** القراءة · الفحص · القياس · كتابة الورق · التقرير.
**ما لا يمرّ بلا ختم:** أي تعديل كود · أي تشغيل يمسّ حسابًا · أي نشر · أي أرشفة.

**والإذن لا يُورَّث:** ختمٌ على وحدة لا يمتدّ للتي تليها، وإذنُ فتح النواة **يُطلب من
جديد في كل مرّة**.
