## ٥. تجمّد البثّ الحيّ باللوحة (الشارت/اللوحة الجديدة عالقة على «بانتظار…»)

**الملف:** `governance/unified_hub.py` — دالّة `_ws_relay`
```diff
  self.connection.sendall(<ردّ المصافحة 101>)
+ # الأطر الملتصقة بالمصافحة كانت تُرمى فتتزحزح محاذاة البثّ — صُحّح بتمريرها:
+ _, _, _leftover = response.partition(b"\r\n\r\n")
+ if _leftover: self.connection.sendall(_leftover)
```
**السبب:** الهب كان يرمي بايتات أوّل إطار بثّ ملتصقة بردّ المصافحة، فيتجمّد البثّ
الحيّ بعد اللقطة الأولى (قِست وقتها: 1 رسالة بس بدل 180+).
**الحالة اليوم:** ⚪ **لم يُعَد فحصها اليوم تحديدًا** بنفس الطريقة (عدّ رسائل WS
الخام) — لوحظ اليوم إنّ أغلب التبويبات تعرض محتوى حيًّا (91-262 عنصر حسب التبويب)
مما يرجّح إنّ البثّ العامّ يعمل، لكن هذا **ليس تأكيدًا مباشرًا لنفس الفحص المحدّد**.
