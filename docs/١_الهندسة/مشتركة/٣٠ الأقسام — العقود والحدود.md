- **مسموح:** متوسّطات · انحدار · ATR · ROC · انحراف معياريّ · حجم · سبريد · وقت · ارتباط.
- **ممنوع:** BOS · CHoCH · MSS · سيولة · Order Blocks · FVG · دلتا · CVD · احتمال · استراتيجيّة · شراء/بيع.

## ٢٠٠ — بنية السوق
قمم/قيعان → هيكل خارجيّ/داخليّ → BOS/CHoCH → MSS → حالة اتجاه → طور → مدقّق → ناشر → المخزن.
- **📏 القاعدة القياسيّة:** **القمة/القاع = شمعتان كل جهة** (تأكيد متأخّر بالضرورة — طبيعة المفهوم) · **الكسر = إغلاق شمعة** فوق/تحت المستوى، **لا فتيلة**.
- **الغالب «لا جديد»** — أغلب الشموع بلا قمّة ولا كسر، وهذا أمين لا نقص.
- **ممنوع:** السيولة (250) · الاحتمال (350) · القرار (400+).

## ٢٥٠ — السيولة وتدفّق الأوامر
برك السيولة (عند القمم/القيعان) → سيولة شراء/بيع → **الكنس** → FVG → مدير → مدقّق → ناشر → المخزن.
- **الكنس = فتيلة تتجاوز البركة** (يفرق عن كسر البنية = إغلاق)، والبركة المكنوسة **تُزال فلا تُكنَس مرّتين** · **FVG = ثلاث شموع** قياسيّ.
- **دلتا/CVD/امتصاص:** تحتاج حجم بيع/شراء حقيقيًّا وعمقًا → **خطّافات صادقة تعلن UNAVAILABLE ولا تخترع حسابًا**.
  **✅ والحكم صار قطعيًّا بقياس ٢٠٢٦-٠٨-٢١:** سُئل `cServer` عبر FIX مباشرة — طُلبت مداخل صفقات (`269=2`) فجاء **صفر**، وطُلبت شراء+بيع+صفقات فجاء 757 شراء و755 بيع و**صفر صفقة**. ثلاث واجهات مستقلّة (الإكسبرت · cAlgo · FIX) بنفس الجواب ⇒ **الغياب بنيويّ: عقود فروقات بلا دفتر مركزيّ.** فـ`107` و`256` و`257` و`258` موقوفة بحقّ، **وأيّ دلتا تُشتقّ من قاعدة التِكّة هنا تخمين لا قياس — وتسميتها CVD كذبة.**

## ٣٥٠ — الاحتمالات

## ٤٠٠ — الاستراتيجيّات
