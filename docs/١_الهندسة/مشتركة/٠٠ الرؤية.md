# ١ · الرؤية

**QUANT_NQ منصّة تتوسّع بلا سقف وبلا عنق زجاجة. التداول أوّل تطبيق فوقها، والمكان أكبر
من التداول.**

```
عدّة مصادر        MT5 · cTrader · بايننس · ريثمك …
                  كل مصدر خطّ مستقلّ معزول من لحظة دخوله حتى عمق النظام

كل مصدر → رموز    كل رمز أنبوبه الخاصّ: تحليله وقراره ومخاطره وحده

عدّة حسابات       كل حساب معزول
                  نفس الرمز على حسابين = خطّتان مختلفتان، صفر علاقة

وحدة العزل        (حساب × رمز)

عدّة مخارج        تنفيذ على حسابات MT5 · توصيات لمجموعة تلغرام · بثّ للمالك
```

**الرمز الداخل له دور محدَّد:** تداول وتحليل معًا، أو **تحليل فقط** — مثل `DXY` الذي
يدخل لأنّ ذرّة تحتاجه ولا يُتداول.

## مقياس الحجم — يحكم الهندسة

**«بلا سقف» تعني قدرةً معماريّة لا نموًّا سريعًا.** الواقع المستهدَف:
**٢–١٠ حسابات · عشرات الرموز · نحو ٢٠٠–٤٠٠ ذرّة خلال سنتين.**

**فلا إفراط بهندسة «آلاف الذرّات».** وتعدّد الحسابات يكون **بخيوط داخل الذرّات نفسها**
لا بنسخة ذرّات لكل حساب. الجدار الحقيقيّ هو
`(تردّد الأحداث × عدد المشتركين × ثقل المعالِج) + الذاكرة` — لا عدد الذرّات.

## الاستقلال عن الوسيط

أسعار الوسطاء وأسماؤهم وأوقات إغلاقهم تختلف. **العمل من عندنا لا من عندهم:**

```
أسماؤنا موحّدة        →  708 يحلّ اسم الوسيط إلى الاسم القانونيّ
شموعنا نبنيها         →  لا نأخذ شموع الوسيط
جلساتنا نحسبها        →  حدود المحترفين لا حدود المنصّة
```

**والوسيط النظيف هو المرجع:** طرفيّة واحدة تُعتمد مرجعًا للسعر في التحليل والقرار،
وكل حساب ينفّذ عند وسيطه هو، مع **مراقبة انحراف** تحجب الدخول الجديد لذلك الحساب وحده.
