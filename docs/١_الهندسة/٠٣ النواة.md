**النواة مختومة.** تعديل حرف واحد فيها يكسر البصمة ويوقف الاعتماد.

## ما تقدّمه النواة

| الخدمة | الوصف |
|---|---|
| **ناقل الأحداث** | القناة الوحيدة بين الذرّات |
| **مُحمِّل الذرّات** | يقرأ المانيفست ويُقلع الذرّة ويراقب صحّتها |
| **التحميل الساخن** | يمسح كل خمس ثوانٍ ويعيد تحميل ما تغيّر إصداره |
| **الوقت الرسميّ** | ختم موحّد مصحَّح على كل حدث |
| **واجهة القراءة** | `/api/atoms` · `/api/health` · `/api/metrics` · `/api/boot-report` · `/api/journal` · `/api/rescan` |
| **بثّ حيّ** | `ws://…/ws/events` — firehose يبثّ كل حدث خام للطبقة الثانية |

## التحميل الساخن — كيف يعمل

```
مسح دوريّ كل ٥ ثوانٍ  →  مقارنة بصمة  →  اختصار سريع إن لم يتغيّر شيء
تغيّر الإصدار         →  إعادة تحميل الذرّة وحدها
ذرّة جديدة            →  تُكتشف حيًّا في المسح الدوريّ أو بـ POST /api/rescan
```

**والقاعدة العمليّة:** تغيير الإعداد يحتاج **رفع نسخة** — الإعداد يُعدَّل أوّلًا
والنسخة آخرًا، وإلّا حُمّلت النسخة بإعداد قديم.
