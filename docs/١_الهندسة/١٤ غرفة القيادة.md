# ١٢ · الطبقة الثانية — غرفة القيادة

**طبقة المالك التي يفرض منها سيطرته. عيون في النواة ودماغ فوقها.**

## القيود الثابتة

```
الذرّة لا تعرف الحوكمة    →  حذف الحوكمة لا يغيّر سطرًا داخل ذرّة
الحوكمة تقرأ حقائق خام     →  ولا تفسّرها داخل النواة
مدخل التحكّم واحد          →  بوّابة الأوامر
```

## بوّابة الأوامر — المدخل الوحيد للتحكّم

```
اللوحة تطلب  →  البوّابة تتحقّق  →  الذرّة تطبّق بنفسها  →  تعلن «طبّقت»
                                                             ↓
                                              يُسجَّل: من غيّر ماذا ومتى
```

**لا أحد يدخل جوّا الذرّة ليغيّر إعدادها.** والقيمة الخاطئة تُرفض وتُكمل الذرّة على
القديم.

## اللوحة

```
النقل            وصلة واحدة على ws://…:8010/ws/events + قراءة REST عبر خادم الحوكمة
اللغة            عربيّ كامل · أرقام لاتينيّة (ar-EG-u-nu-latn) · لا إنكليزيّ ظاهر
الترجمة          قاموس صادق لا قناع — لا تُخفي حالةً بترجمتها
الصدق            تعرض ما وصل فقط، والغياب يُعلَن غيابًا
```

**واللوحة هي المنتَج لا الطرفيّة.** سقوطها أعلى إنذار في النظام.
