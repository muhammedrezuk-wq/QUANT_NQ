# فهرس الوثائق النافذة

هذا المجلد هو **المكان الواحد** الذي يرجع إليه أي مطور أو نموذج أو مدقق.

```text
docs/
├── ٠_الدستور/دستور.md
├── ١_الهندسة/هندسة.md
├── ٢_المسارات/المسارات.md
├── ٣_الأحداث/الأحداث.md
├── ٤_الأقسام/الأقسام.md
├── ٥_السياق/السياق.md
├── ٦_التدقيق/التدقيق.md
└── ٩_الأرشيف_غير_النافذ/
```

## قاعدة القراءة

1. ابدأ بـ`٠_الدستور/دستور.md`.
2. اقرأ `١_الهندسة/هندسة.md` لفهم المجلدات وحدودها.
3. اقرأ `٢_المسارات/المسارات.md` قبل تشغيل أو تعديل أي مسار.
4. اقرأ `٣_الأحداث/الأحداث.md` قبل إضافة حدث أو اشتراك.
5. استخدم `٤_الأقسام/الأقسام.md` للوصول إلى الذرة من دون البحث اليدوي.
6. سجّل أي قرار جديد في `٥_السياق/السياق.md` قبل تنفيذه.
7. راجع `٦_التدقيق/التدقيق.md` لمعرفة ما هو مثبت وما هو تحذير.

## مصدر الحقيقة

الوثيقة تشرح ولا تستبدل الكود. مصدر التشغيل هو:

```text
Build Registry → manifests → Core contracts → tests → Release Gate
```

الأرشيف غير نافذ ولا يجوز استخدامه لاتخاذ قرار تشغيل أو إصدار.
