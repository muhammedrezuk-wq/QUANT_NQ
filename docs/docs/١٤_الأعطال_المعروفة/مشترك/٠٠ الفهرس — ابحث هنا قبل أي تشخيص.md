## 🔑 زرّ `.bat` «لا يعمل» أو ينفّذ أسطر `REM` كأوامر

**العَرَض الحرفيّ:**
```
'p' is not recognized as an internal or external command
'internal' is not recognized as an internal or external command
'----------------------------------------------' is not recognized ...
```

**الجذر:** الملفّ بنهايات **`LF`** لا `CRLF`. cmd يحتمل `LF` بالأسطر
البسيطة لكنّه **ينكسر على الكتل** — `if (...)` و`for` — فيفقد حدود السطور
ويحاول تنفيذ ما بداخلها.
**مقاس بـ:** `CR=0 · LF=42` على `غرفة القيادة.bat` · **التاريخ:** 2026-09-01 13:30

**الاتّساع:** كانت **19 من 24** ملفّ `.bat` بهذه الحالة — ومنها
`scripts/py.bat` الذي تناديه كل الأزرار، وزرّا التهيئة والإيقاف،
والخمسة عشر فاحصًا في `governance/launchers/`.

**السبب:** `core.autocrlf=true` مضبوط لكن **لا `.gitattributes`**، والملفّات
كُتبت مباشرة (نسخ من شجرة لينكس) فتخطّت تحويل git عند الـcheckout.

**العلاج المكبوس:** `.gitattributes` يفرض `eol=crlf` على `bat/cmd/ps1`.
**لكن:** ملفّ تكتبه بأداة تكتب `LF` يتخطّى القاعدة — **تحقّق من `CRLF`
قبل أن تلوم أيّ زرّ**:
```powershell
$b=[IO.File]::ReadAllBytes($f); ($b|?{$_ -eq 13}).Count -eq ($b|?{$_ -eq 10}).Count
```
