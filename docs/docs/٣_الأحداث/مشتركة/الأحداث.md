# قاموس الأحداث — QUANT_NQ

**هذا هو الملف الوحيد الذي يرجع إليه المطور لمعرفة الحدث وناشريه ومستمعيه.**

## القواعد النافذة

- التواصل بين الذرات عبر EventBus فقط؛ لا استيراد مباشر بين الذرات.
- اسم الحدث نقطي واضح، ومعناه ثابت؛ أي تغيير جوهري يحتاج إصدار عقد جديد.
- حمولة الحدث قابلة للتسلسل وتحتوي أثرًا ووقتًا ومصدرًا عند النشر.
- الأحداث المنتهية بـ`.state` أو `.synced` أو `.snapshot` قابلة لإعادة الحالة.
- أحداث الأوامر لا تُعاد ولا تُخزّن حتى لا يتكرر التنفيذ.
- `asset.portfolio.owner_intent.state` هو حدث الحالة الرسمي الجديد لـ519، والحدث القديم محفوظ للتوافق.
- الأسماء التالية مستخرجة من المانيفستات الحالية؛ لا تُكتب يدويًا في هذا الجدول.

## أرقام الاكتشاف الحالية

- المكونات ذات المانيفست: **309**.

- أحداث لها ناشر: **391**.
