# مسار الدخول — من السعر إلى الأقسام

**أوّل ثلاث محطّات في رحلة التِكّة.**

## أ · السعر يدخل

```
622  جسر cTrader FIX     →  feed.ctrader.tick · market.depth
618  جسر MT5             →  التِكّات والمواصفات من قاعدة الجسر
620  ياهو                →  مرجع
                            ↓
613  تغذية السوق         →  توحيد الهويّة وتمرير التِكّة — market.tick
                            ↓
112  مدقّق البيانات       →  محطّة التدقيق — الناشر الوحيد
                            ↓
                     market.tick.validated
```

**والهويّة تُحقن عند المصدر وتنساب مع السلسلة كلّها:**
`account_id · broker · symbol · provider · sequence · tick_id`.

## ب · التِكّة القانونيّة

`shared/tick_contract.py :: as_validated_tick` هو المحوّل القانونيّ الوحيد. يشتقّ هويّة
التِكّة بسلسلة احتياطيّة:

```
tick_id  →  sequence  →  event_id  →  period_start  →  "stamp@bid:ask"
```

## ج · الأقسام تشتغل بالتوازي

كل قسم يفتح دورة، يجمّع نتائج وحداته، ثمّ يُخرج بطاقته الثمانيّة.
