# ٣ · الرؤية بوصفها قيدًا لا إلهامًا

المشروع محاولة رقم **٧٣ تقريبًا**. شُرحت الرؤية ثلاثًا وسبعين مرّة، وانكسرت كل مرّة
بالطريقة نفسها:

- بناء من الصفر ومسح كل شيء **مرّتين** (عشرة أيام مرّة · نحو ثلاثة آلاف ذرّة مرّة).
- **يقين خاطئ لدى المنفّذ** وبناء على «هكذا نشتغل» لا على الرؤية، ثمّ اعتراف متأخّر.
- كلمة **«مختبَرة» كذبة متكرّرة**: ألفان ومئة وواحد وخمسون اختبارًا أخضر وفيها ثلاثة أعطال قاتلة.
  **«مختبَرة» ليست «شغّالة».**

**المقياس المطلق: الرؤية أو لا شيء.** شيء يبعد مليون دولار عن الشغل ولا يطابق الرؤية
→ **يُحذف**. «قريب لكنّه ليس الرؤية» = باطل، وهو نفسه الذي تراكم ثلاثًا وسبعين مرّة.

**صفة المالك التي تحكم أسلوب المخاطبة:** صاحب الرؤية وهندسة المشروع. **ليس مبرمجًا ·
لا يقرأ الإنكليزية · لا يتعامل بالمصطلح التقنيّ.** يُحمَل عنه التقنيّ كلّه، ويُخاطَب
بلغة بسيطة.
