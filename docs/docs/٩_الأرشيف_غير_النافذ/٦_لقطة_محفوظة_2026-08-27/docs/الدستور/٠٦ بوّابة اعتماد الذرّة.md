# ٧ · البوّابة — كيف تُعتمد الذرّة

```
١ · بنيويّ    validate_atoms يفحص كل قواعد الدستور — لا يمرّ خرق
٢ · حيّ       الذرّة تقلع على النواة الحقيقيّة الشغّالة، وتتصرّف صحّ على بيانات
              حقيقيّة، والمالك يراها بعينه   ← شرط التسليم الإلزاميّ
٣ · الحكم     تثبت · تُصلَّح بالسبب · تُعرَض على المالك
```

**المدقّق والاختبار يكذبان في الاتّجاهين — مثبَت:** اختبارات `611`/`601`/`609`/`618`
فشلت وهي شغّالة حيًّا، و`611` مرّ المدقّق وهو يُسيء تصنيف حالته حيًّا.

> **«خلصت» تعني: مرّت الفحص الحيّ أمام المالك — لا «مدقّق أخضر».**

**درس الجوع:** ذرّة `degraded` بسبب جوع مدخل من عطل أعلى منها **مجوَّعة لا فاشلة** —
لا تُلام ذرّة جوّعها غيرها.
