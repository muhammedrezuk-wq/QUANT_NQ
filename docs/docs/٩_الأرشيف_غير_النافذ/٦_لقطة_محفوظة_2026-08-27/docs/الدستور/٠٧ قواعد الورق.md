# ٨ · قواعد الورق

1. **الورق هو الأساس، ويُسجَّل أوّلًا بأوّل** — لا بالآخر ولا بدفعات.
2. **الواقع فوق الورق.** الورق مرجع وتاريخ لا قيد. ما لا يطابق الواقع، الواقع يربح.
3. **ورقة تشريح قبل كل وحدة تنفيذ**، وتُجاب كل أسئلتها قبل أيّ سطر كود.
4. **لا رقم يُعلَن بلا مصدر مقيس.** التوقّع ليس قياسًا، و«لا أعرف» + اسم الفحص أشرف
   من تخمين يُبنى عليه.
5. **بندٌ واحد لا يُكتب مرّتين.** ورقة واحدة لكل غرض، ولا تداخل بينها.
6. **الورقة التي صُحّحت تُؤرشَف** في اللحظة نفسها.
