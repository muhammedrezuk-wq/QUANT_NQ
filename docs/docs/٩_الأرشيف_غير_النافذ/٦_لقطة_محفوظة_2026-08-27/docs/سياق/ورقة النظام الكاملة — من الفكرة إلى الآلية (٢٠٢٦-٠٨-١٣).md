# ورقة النظام الكاملة — من الفكرة إلى الآلية

**كلام المالك · 2026-08-13 · المرجع الأعلى للفكرة.**
**القسم الأخير وحده ليس من كلامه: هو قياس النظام على هذه الورقة.**

---

## ١ — الفكرة الأساسية
النظام ليس **صفقة تدخل ثم تُغلق**. كل أصل ماليّ عنده **مركز مستمرّ** يتغيّر مع السوق، وكل أصل يعمل **مستقلًّا**: الذهب 50$ · ناسداك 50$ · النفط 50$ — لكل واحد نظامه ومخاطره ومركزه منفصلًا.
**الـ50$ الأساسيّة لا تُسحب ولا تُعتبر ربحًا. هي قاعدة تشغيل النظام.**

## ٢ — الحالات
ثلاث حالات: **شراء · محايد · بيع**. وداخلها تحوّط:
`شراء 100 + بيع 30 = صافي شراء 70` · `بيع 100 + شراء 40 = صافي بيع 60`.
**التحوّط لا يعني أنّ النظام انتهى — هو طريقة لتخفيف التعرّض وتغيير المركز تدريجيًّا.**

## ٣ — بداية المركز
النظام لا يبدأ متأكّدًا من الاتّجاه. يبدأ بـ**`BUY + SELL`** والصافي قريب من الصفر. **ليست صفقة هدفها الربح** — هي نقطة بداية تسمح بمراقبة السوق ثمّ ترجيح جهة. وبعد الدليل: `BUY > SELL` ⇒ صافي شراء · `SELL > BUY` ⇒ صافي بيع.

## ٤ — بناء الاتّجاه
**لا يقول «ظهر اتّجاه فأدخل بأقصى حجم».** يبني تدريجيًّا: محايد → شراء 20 → 40 → 60 → 80.
وكل زيادة مربوطة **بميزانيّة المخاطر المسموحة للأصل**، لا بالرغبة.
**إن قوي الاتّجاه أُعطي مساحة ليكبر، وإن ضعف لا يُجبَر النظام على البقاء مكشوفًا بالكامل.**

## ٥ — ضعف الاتّجاه
`شراء 100` → ظهر ضعف → `شراء 100 + بيع 30` (صافي 70) → `شراء 100 + بيع 60` (صافي 40) → غموض → `شراء 100 + بيع 100` (محايد).
**شراء → شراء متحوّط → محايد، بلا قتل النظام.**

## ٦ — الانعكاس
`شراء 100 + بيع 100` → `شراء 60 + بيع 100` (بيع 40) → `شراء 30 + بيع 100` (بيع 70) → `شراء 0 + بيع 100` (بيع 100).
**ليس «أغلق ثمّ افتح» بل: شراء → تحوّط → محايد → بيع. وهذا جوهر الفكرة.**

## ٧ — وظيفة وقف الخسارة
**ضرب الوقف ≠ انتهى النظام.** الوقف **حدّ حماية للمركز الحاليّ**. عند بلوغه:
١) تُعتبر الفرضيّة ضعفت أو فشلت · ٢) يُعاد حساب التعرّض · ٣) يزيد التحوّط أو يقلّ الاتّجاه · ٤) إن تأكّد الانعكاس ينتقل للجهة الأخرى · ٥) وإلّا يبقى محايدًا.
**الوقف يغيّر حالة المركز، ولا يوقف النظام بالضرورة.**

## ٨ — وقف متحرّك
ليس ثابتًا؛ يتحرّك مع الاتّجاه بقاعدة من: آخر قاع/قمّة · مقدار الحركة · التقلّب · نسبة المخاطرة · أو قاعدة مركّبة. **محدَّدة مسبقًا وقابلة للاختبار، لا حسب الشعور.**

## ٩ — إذا انضرب الوقف وأنت متحوّط (أهمّ نقطة)
`شراء 100 + بيع 40` وضُرب وقف الشراء ⇒ **لا يُقال «أغلق كل شيء»**، بل: ما حالتي الجديدة؟
انعكاس غير مؤكّد ⇒ **زد التحوّط**. اتّجاه هابط ⇒ **قلّل الشراء وزد البيع**:
`100/40` → `60/60` → `20/80` → `0/100`. **انتقال من شراء إلى بيع بلا توقّف شامل.**

## ١٠ — التحوّط ليس هدفًا
البقاء `شراء + بيع` أبدًا له **تكلفة ومخاطر تنفيذ وتمويل وفروقات سعر**. يُستعمل للحماية أو تخفيف التعرّض أو الانتقال، **ويُفكّ تدريجيًّا** حين يعود الاتّجاه: `100/50` → `100/30` → `100/10` → `100`.

## ١١ — ميزانيّة كل أصل
مستقلّة تمامًا. **خسارة الذهب لا تُعوَّض من ناسداك، وربح ناسداك لا يُعطى للذهب.** لكل أصل: حالة + مركز + مخاطرة + أرباح + نموّ، منفصلة.

## ١٢ — الـ50$ الأساسيّة
**القاعدة الأساسيّة للأصل.** لا يُقال «ربحت 50 فصار عندي 100 وأسحب منها». يُفصَل:
**رأس المال الأساسيّ = 50$** (لا يدخل سلّم السحب) · **الربح المحقَّق** (وهو ما يدخل السلّم).

## ١٣ — سلّم تحقيق الأرباح
**50 → 100 → 200 → 400 → 800 → 1600 → 3200 → 6400 …** كل مرحلة **ضعف** سابقتها، وعند بلوغها يُعتبر الربح **محقَّقًا**.

## ١٤ — قاعدة السحب
عند كل مرحلة: **نصفها يخرج للمالك، ونصفها يبقى للنموّ.**

| الربح المحقَّق | السحب | يبقى للنموّ |
|---:|---:|---:|
| 50$ | 25$ | 25$ |
| 100$ | 50$ | 50$ |
| 200$ | 100$ | 100$ |
| 400$ | 200$ | 200$ |
| 800$ | 400$ | 400$ |
| 1600$ | 800$ | 800$ |
| 3200$ | 1600$ | 1600$ |

**والـ50$ الأساسيّة تبقى منفصلة.**

## ١٥ — السحب تراكميّ لا إعادة ضبط
50 ⇒ 25 · ثمّ 100 ⇒ 50 إضافيّة · ثمّ 200 ⇒ 100 · ثمّ 400 ⇒ 200.
**المجموع حتى مرحلة 400 = 25+50+100+200 = 375$**، والـ50$ الأساسيّة ما زالت منفصلة.

## ١٦ — لماذا هذه الآليّة
لا: «النظام ربح فأغلق وخذ الربح». بل: **إن أثبت النظام قدرته على مرحلة أكبر، أخرِج جزءًا وأعطِ الباقي للنظام ليتعامل مع مرحلة أكبر.**
**ربح → جزء لك → جزء للنموّ → حجم أكبر → مرحلة أكبر → سحب أكبر.**

## ١٧ — العلاقة بين النموّ والتداول
50$ أساسيّة → تداول → التقط اتّجاهًا: **يكبر المركز** · ضعف: **يخفّف أو يتحوّط** · انعكس: **ينتقل تدريجيًّا** · حقّق الربح: **يثبّته عند مرحلة السحب** → نصف يخرج ونصف يبقى، **فيكبر رأس المال العامل مع الوقت.**

## ١٨ — مثال كامل على أصل واحد
ذهب 50$ → محايد → اتّجاه صاعد → شراء → يقوى فيزيد → ربح +50$ ⇒ **25 للمالك و25 للنموّ**، **ولا يُغلق الذهب لمجرّد بلوغ المرحلة**. يستمرّ: قوي ⇒ يزيد بقواعد المخاطر · ضعف ⇒ تحوّط · انعكس ⇒ صافي شراء إلى محايد إلى بيع. ثمّ +100$ ⇒ 50/50 · ثمّ 200 ⇒ 100 · ثمّ 400 ⇒ 200.

## ١٩ — لا «انتهاء نظام» بسبب صفقة واحدة
لا «ربحت فانتهت» ولا «خسرت فانتهى كل شيء»، بل: **ما حالة الأصل الآن؟**
`شراء → تحوّط → شراء` · `شراء → تحوّط → محايد → بيع` · `بيع → تحوّط → محايد → شراء`.

## ٢٠ — الشكل النهائي

```

                      │
               رأس مال أساسي 50$
                      │
                   محايد
                 BUY + SELL

```

### الخلاصة بكلامه
**نظام مستمرّ لإدارة المركز، لا استراتيجيّة صفقات منفصلة.** لكل أصل 50$ مستقلّة. يبدأ محايدًا، يرجّح جهة بالتحليل، يزيد عند التأكيد، يتحوّط عند الضعف، ويغيّر الاتّجاه تدريجيًّا عند الانعكاس. **الوقف لا يقتل النظام؛ يغيّر حالة المركز ويحميه.** وبالتوازي سلّم `50→100→200→400→800…` بنصف للمالك ونصف للنموّ، والـ50$ الأساسيّة ثابتة.

## الخلاصة المقيسة
**ثلاثة عشر بندًا من عشرين مبنيّة ومطابقة.** والخروقات الثلاثة الحقيقيّة كلّها **جذرها واحد**: بدأ المركز **رجلًا واحدة اتّجاهيّة** بدل الزوج المحايد، فدخل من مسار يفرض `SL/TP` كلاسيكيًّا، فصار الوقف يقتل المركز بدل أن يغيّر حالته.
