# ١٤ · حدود التوسّع — ما يُبنى وما لا يُبنى

## يُبنى

- **مصدر جديد** = جسر جديد في نطاق `600`، بلا مساس بما فوقه.
- **رمز جديد** = أنبوب جديد داخل الذرّات نفسها، لا نسخة ذرّات.
- **حساب جديد** = خيط جديد داخل الذرّات نفسها.
- **توحيد** = **طبقة فوق** الذرّات المعزولة، لا على حساب العزل ولا الدقّة.

## لا يُبنى

- **نسخة ذرّات لكل حساب** — الجدار في تردّد الأحداث لا في عدد الذرّات.
- **هندسة «آلاف الذرّات»** — المستهدَف ٢٠٠–٤٠٠ خلال سنتين.
- **قراءة أنبوب لحالة أنبوب آخر** — الأنابيب تلتقي عند المحفظة بالرؤية لا بالقرار.
- **منطق قرار داخل طبقة المحفظة** — قراءة فقط، ولا ترسل أمرًا أبدًا.
