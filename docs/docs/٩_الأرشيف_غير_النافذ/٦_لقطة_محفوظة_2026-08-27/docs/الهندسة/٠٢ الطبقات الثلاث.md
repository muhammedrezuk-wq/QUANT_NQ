# ٣ · الطبقات الثلاث

```
┌──────────────────────────────────────────────────────────┐
│  ٢ · الحوكمة                                              │
│     عيون داخل النواة تبلّغ حقائق خام                       │
│     + دماغ فوقها يفهم ويعرض ويتحكّم                        │
│     طبقة المالك التي يفرض منها سيطرته                     │
└──────────────────────────────────────────────────────────┘
                          ▲  حقائق خام
┌──────────────────────────────────────────────────────────┐
│  ١ · النواة                                               │
│     الأساس المختوم · لا تُسأل · مصنع «غبيّ» يشتغل ٢٤/٧      │
│     مجمّدة وجاهلة (Zero-Knowledge) فلا تصير عنق الزجاجة     │
└──────────────────────────────────────────────────────────┘
                          ▲  أحداث
┌──────────────────────────────────────────────────────────┐
│  ٣ · الذرّات                                              │
│     معزولة · مكتفية بذاتها · تتواصل بالأحداث فقط          │
└──────────────────────────────────────────────────────────┘
```

**المبادئ الأربعة التي تجعل التوسّع ممكنًا:**

1. **نواة مجمّدة وجاهلة** — لا تعرف ماذا تفعل الذرّات، فلا تصير عنق زجاجة.
2. **عزل صارم** بين الذرّات.
3. **تواصل بالأحداث فقط.**
4. **حالة مفصولة لكل حساب.**

**والحُكم يُسحب من النواة إلى الخارج:** المصنع يشتغل، والسيطرة فوقه بيد المالك، بلا
كسر عزل الذرّات.
