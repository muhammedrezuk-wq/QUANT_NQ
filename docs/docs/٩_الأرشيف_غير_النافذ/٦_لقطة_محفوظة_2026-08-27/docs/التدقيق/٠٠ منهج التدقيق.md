# منهج هذا التدقيق

```
كل رقم فيه       مأخوذ من كود حيّ أو من واجهة النواة الشغّالة أو من قاعدة الجسر
لا رقم بلا مصدر  والتوقّع ليس قياسًا
عند التعارض      الكود هو الحقيقة، والورقة هي التي تُصحَّح
الغياب يُعلَن     ما لم يُقس يُكتب أنّه لم يُقس، ولا يُستَر
```
