# مواصفة رمز واحدة في القاعدة، والنظام يغذّي رمزًا آخر

```
618 يقرأ الجدول:  symbol_specs_v2   →  صفّ واحد:  BTCUSD
الجدول القديم:    symbol_specs      →  ثمانية:    AMD · NVDA · INTC · AUDUSD
                                                  XAUUSD · EURUSD · USTEC · BTCUSD
```

**و`USTEC` — أي ناسداك، أداة المشروع باسمه — مواصفتها في الجدول القديم فقط.**

```
618  published=102,510   symbols=1
708  resolved=0                       ← لا رمز محلولًا
513  SIZING_UNAVAILABLE_FOR_SYMBOL    ← لا تحجيم
```

**⇒ النظام يقيس ناسداك بأربعٍ وعشرين ذرّة تحليل، ولا يعرف كيف يحسب لوتًا واحدًا لها.**

**والأخطر الصمت:**

```python
# 618
if not usable:
    return          # ← بلا تحذير · بلا عدّاد · بلا صحّة متدهورة
```

فلو فرغ جدول المواصفات، **لا شيء يُعلن ذلك**. يُكتشف من `513` بعد ثلاث محطّات.
