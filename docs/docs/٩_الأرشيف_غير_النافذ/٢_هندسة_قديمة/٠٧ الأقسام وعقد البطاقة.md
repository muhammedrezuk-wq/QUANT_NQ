# ٨ · الأقسام الستّة وعقد البطاقة

**كل قسم يُخرج بطاقة واحدة موحّدة الشكل — هذا هو قانون النظام كلّه.**

```
150  التحليل            →  analysis.section.live
200  بنية السوق         →  structure.section.live
250  السيولة            →  liquidity.section.live
300  الإحصاء            →  stats.section.live
350  الاحتمالات         →  probability.section.live
400  الاستراتيجيّات      →  strategy.section.live
```

## العقد الموحّد — ثمانية حقول لكل رمز

```
direction        الاتّجاه       −100 … +100
strength         القوّة          0 … 100
confidence       الثقة          0 … 100
current_depth    العمق الحاليّ   0 … 100
required_depth   العمق المطلوب  عتبة القسم
weight           الوزن          وزن القسم في القرار
ratio            النسبة         المساهمة الفعليّة
state            الحالة         READY | NOT_READY
```

**والقسم لا يُحسب في القرار إلا إذا كانت حالته `READY`.**
**وثلاث بوّابات متتالية على العتبة نفسها:** الوحدة → المجمّع → القسم.

## داخل الأقسام

| القسم | ما يقيسه |
|---|---|
| **١٠٠ الاستقبال** | التِكّات والعمق وحالة الرمز · بناء الشموع |
| **١٥٠ التحليل** | مساران: سريع بإيقاع التِكّة، وبطيء بإيقاع الشمعة — يُدمجان في `166` |
| **٢٠٠ البنية** | القمم والقيعان · الهيكل الداخليّ والخارجيّ · `BOS` · `CHoCH` · `MSS` · طور السوق |
| **٢٥٠ السيولة** | مجمّعات السيولة · سيولة الشراء والبيع · الكنس · الفجوة `FVG` · الدلتا · `CVD` · الامتصاص |
| **٣٠٠ الإحصاء** | سبع عشرة وحدة إحصائيّة |
| **٣٥٠ الاحتمالات** | نماذج الاحتمال والتعلّم |
| **٤٠٠ الاستراتيجيّات** | سبع استراتيجيّات اتّجاهيّة + أربعة سياقات + مجمّع |

## الاستراتيجيّات السبع والسياقات الأربعة

```
اتّجاهيّة   trend_continuation · reversal_potential · breakout_acceptance
           pullback_quality · momentum_expansion · range_rotation · liquidity_raid

سياق       entry_structure_quality · invalidation_quality · news_regime · session_regime
```

**السياق لا يقرّر اتّجاهًا — يضرب في وزن الاتّجاهيّات (`context_factor`).**
