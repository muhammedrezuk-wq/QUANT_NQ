# ٧ · الذرّة

**الذرّة وحدة عمل معزولة مكتفية بذاتها، تُحمَّل ساخنة، ولا تعرف غير عقدها.**

```
atom.py          الكود — إنكليزيّ خالص · ≤ ٣٥٠ سطرًا فعليًّا
manifest.yaml    البطاقة — السيّد الذي تقرأ منه النواة كل شيء
الشرح.md         التوثيق الكامل بالعربيّة · ومنه «من يقرأ مخرجاتي»
التاريخ.md       سطر لكل تعديل: ماذا · لماذا · متى
tests/           المسار الطبيعيّ وأهمّ حالات الفشل
```

**دورة الحياة:** `initialize` → `start` → `stop` → `shutdown`، وكلّها `async`،
و`health_check` تعلن الحالة والرسالة.
**و`snapshot`/`restore` لمن يحتاج بقاء حالته عبر إعادة التحميل.**

**العدد الحاليّ: ٢٢٥ مجلَّد ذرّة**، منها أربع مستبعَدة من الإقلاع باستثناء معلَن لا تُقلع
تلقائيًّا بالقصد.
