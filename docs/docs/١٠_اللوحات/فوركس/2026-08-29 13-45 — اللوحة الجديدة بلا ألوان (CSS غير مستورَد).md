## التشخيص — مقاس لا مخمَّن

| القياس | النتيجة |
|---|---|
| أصناف يستعملها المكوّن | `dl-root` · `dl-panel` · `dl-room-card` … (عشرات) |
| `styles-dashboard.css` بالمصدر | ✅ موجود — **470 سطرًا** |
| ذكر `dl-` في `built/assets/*.css` | 🔴 **صفر** |
| مَن يستورد الملفّ | **لا أحد** |

```
main.tsx                 → import './styles.css'              ✅
CryptoDashboard.tsx      → import './crypto-dashboard.css'    ✅
NewDashboard.tsx         → (لا استيراد)                        🔴
```

**السبب الجذريّ:** Vite لا يضمّ ملفّ CSS إلى الحزمة إلا إذا استورده أحد. الملفّ
كان يتيمًا ⇒ **لم يدخل البناء إطلاقًا** ⇒ التبويب يُصيّر نصًّا خامًا بلا ألوان
ولا بطاقات.

*(ملاحظة على نفسي: سُئلت عن هذا سابقًا في الجلسة وقستُ «251 قاعدة CSS مطبَّقة»
فاستنتجتُ «كاش كروم» — **وكان استنتاجًا خاطئًا**: القواعد كانت للهيكل العام
(header/nav) لا لمحتوى التبويب. القياس الصحيح هو مطابقة أصناف المكوّن نفسه
بالـCSS المبنيّ، لا عدّ القواعد الكلّي.)*
