## العيوب المثبتة

1. خادم الحوكمة كان يقرأ `atoms/` باستعمال `iterdir()` فقط، بينما الذرّات موجودة داخل مجلدات الأقسام. النتيجة: أسماء فارغة، شبكة بعقد صفر، وإعدادات ذرات لا تصل.
2. واجهة React المبنية كانت مستثناة من `.gitignore`، فلم يكن مسار `governance/ui/built/` موجودًا في النسخة العامة.
3. مسارات الترجمة الاحتياطية كانت تعيد بعض الرموز والرسائل الإنكليزية الخام.
4. لوحة الكريبتو كانت تستعمل `mapOf` غير معرّفة عند فتح تبويب الحواس.
5. زر الإيقاف الطارئ في اللوحة الجديدة كان يحتوي `TODO` ولا يرسل الأمر.
6. النسخة العامة كانت تحتوي نسخًا مكرّرة من runtime داخل `forex_runtime/` و`crypto_runtime/`، ما يسبب تضاربًا وفحصًا كاذبًا للملفات.

## الإصلاحات المنفّذة

- اكتشاف متكرر لكل المانيفستات داخل خادم الحوكمة.
- تفعيل fallback آمن للواجهة المبنية، مع إدراج build canonical داخل الحزمة.
- توحيد fallback العربي للحالات والأحداث والحقول والمصادر.
- إصلاح لوحة الكريبتو وتلخيص الحمولة بدل عرض JSON خام.
- ربط زر الإيقاف الطارئ بمسار `dangerCommand('halt')` الموجود أصلًا.
- إزالة النسخ المكررة من runtime والإبقاء على مجلدي التشغيل وملفات baseline اللازمة.
- إضافة الوثائق العربية النافذة إلى `docs/`، مع إبقاء الأرشيف في مجلد غير نافذ.

## حدّ التداول الحقيقي
