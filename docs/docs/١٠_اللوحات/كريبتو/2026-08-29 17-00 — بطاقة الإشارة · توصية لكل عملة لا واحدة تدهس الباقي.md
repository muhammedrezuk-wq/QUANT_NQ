# بطاقة الإشارة — توصية لكل عملة، لا واحدة تدهس الباقي

**التاريخ:** 2026-08-29 17:00
**الأمر:** «بطاقة الحيّة إذا صارت توصيات صفقات، إذا 1 لازم 5 عملات توصل توصيات»

---

## النكشة

`#2277` ينشر **بطاقة لكل رمز** على اسم حدث واحد: `crypto.decision.signal_card.state`.
ومخزن اللوحة يحفظ **آخر قيمة فقط لكل اسم حدث**:

```ts
setEvent: (name, payload) => set((s) => ({ streams: { ...s.streams, [name]: payload } }))
```

فبطاقة العملة الخامسة **تدهس** الأربع قبلها، ولا يُرى إلا رمز واحد.

**البطاقات لم تكن تضيع من النظام — بل من العين. وهذا يكفي لتضيع صفقة.**

## القياس الذي أثبت أنّ الخلل بالعرض لا بالمحرّك

### ١) `#2275` لا يرمي أي مرشّح منافس

```python
ranked = sorted(self._recent.items(), key=lambda kv: self._rank_key(kv[0], kv[1][0]))
competing_rank = next((i for i, (s, _) in enumerate(ranked) if s == symbol), 0)
...
await self._context.publish(EVENT_OUT, {"symbol": symbol, "approved": True, ...
                                        "competing_rank": competing_rank,
                                        "competing_count": len(self._recent), ...})
```

الترتيب **معلومة مرفقة** لا بوّابة إقصاء. كل مرشّح يمرّ بـ`approved: True`.

### ٢) السجلّ الدائم يشهد

```

```

**فالمحرّك كان يُصدر لعملات كثيرة منذ البداية. اللوحة وحدها كانت تدهس.**

## الإصلاح — ثلاث طبقات

**١) بطاقة حيّة لكل رمز:** `liveCards: Record<symbol, SignalCard>` بدل قيمة واحدة.

**٢) بطاقة كاملة لكل عملة لا شريط أسماء:** فُصل العرض إلى مكوّن `FullCard`
يُرسم لكل عملة بكل حقوله (المرساة · الدخول · سلّم الدخول · الوقف · الهدفان ·
الراكض · الإلغاء · الوقف الزمنيّ · أقصى مخاطرة · المتنافسة · خبر طازج).
**توصية بلا أرقامها لا تُنفَّذ.**

**٣) بذر من السجلّ الدائم:** البطاقات الحيّة تتجمّع بعد فتح الصفحة فقط، فكانت
اللوحة تقول «ما وصلت بطاقة» بعد 37 توصية — كذبة. الآن تُبذَر بآخر توصية لكل
عملة من `/gov/decisions`، **موسومة «من السجلّ — الحقول المحفوظة فقط»** فلا
تلبس ثوب البطاقة الحيّة الكاملة. وحين تصل بطاقة حيّة لعملة تحلّ محلّ سطر سجلّها.
