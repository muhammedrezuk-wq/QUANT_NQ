# حدود الأمان — رقما الفضيحة أُغلقا، وبقي رقم اختبار واحد

```yaml
# 516 قاطع الأمان — المانيفست الحيّ (v5.2.0)
max_daily_loss_pct:      5.0      ← (تحديث ٢٥-٠٨: كانت 20.0 — أُغلقت بختم nq في v5.1.0، عيار لوحة)
max_consecutive_losses:  10       ← (تحديث ٢٥-٠٨: كانت 998 — أُغلقت بختم nq، عيار لوحة)
max_daily_trades:        200
max_open_trades:         20
max_reserved_risk_pct:   100.0    ← 🔴 كامل الحساب معرَّضًا — ما زال رقم اختبار
```

**على حساب ٦١٦ دولارًا:** الخسارة اليوميّة المسموحة نحو **٣١ دولارًا** (5%)، **وكامل الرصيد
ما زال قابلًا للحجز** — `max_reserved_risk_pct: 100.0` لم يُمسّ.

**والمقيس حيًّا وقت الكتابة كان: `516 accounts=1 validations=0`** — لم يكن تحقّق من أمر قط.
**(تحديث ٢٥-٠٨ ليلًا: أوّل صفقة بتاريخ النظام مرّت عبر `516 v5.2.0` — الحدود دخلت الخدمة فعلًا،
والقاطع صار بحسمٍ مع زرّ رفعٍ بيد المالك.)**
