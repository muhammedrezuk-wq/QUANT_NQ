# إصلاح زر «غرفة القيادة.bat» — مسار ناقص

**تاريخ التنفيذ:** 2026-08-28 20:37 (بتوقيت الجهاز)
**الختم:** `NQ` — أمر المالك الصريح «عدّلها NQ».

---

## العطل (مقاس، لا تخمين)

`أزرار التشغيل\غرفة القيادة.bat` سطر 2 كان:
```bat
cd /d "%~dp0"          ← يذهب لمجلّد «أزرار التشغيل» نفسه
call scripts\launch_unified.bat
```
فيبحث عن `أزرار التشغيل\scripts\launch_unified.bat` — **غير موجود**، بينما
الملفّ الحقيقيّ في جذر المشروع `scripts\launch_unified.bat`. النتيجة: الزرّ
لا يعمل إطلاقًا.

**التأكيد بالمقارنة:** كل الأزرار السليمة بنفس المجلّد تستعمل `"%~dp0\.."`
(مثال مقاس: `غرفة القيادة الموحدة.bat`) — هذا الزرّ وحده كان ناقصه `\..`.

## الإصلاح

```diff
- cd /d "%~dp0"
+ cd /d "%~dp0\.."
```
**سطر واحد. لم يُمسّ أي شيء آخر.** تحقُّق بعد التعديل: مسار الهدف
`scripts/launch_unified.bat` موجود وصحيح.

## علاقته بالتجميد

- **حارس السلامة (#007):** مجلّد «أزرار التشغيل» **خارج `watched_dirs`
  تمامًا** (المراقَب: atoms · core · governance · scripts · config · shared …)
  — مقاس مباشرة من منيفست الذرّة. فالتعديل **لا يكسر الحارس التقنيّ**.
- **ورقة التجميد (`FRZ-20260827-F39E291C`):** تذكر «أزرار التشغيل» ضمن
  الممنوعات نصًّا. **نُفِّذ التعديل بختم `NQ` صريح من المالك** — وهو المسار
  الوحيد المسموح وفق البند ٣ من ورقة «NQ ختم مالك».

## ملاحظة جانبيّة مرصودة (بلا تنفيذ)

يوجد مجلّد **`QUANT_NQ_RC7`** (21 ميغابايت، نسخة مشروع كاملة بداخلها
`atoms/`, `core/`, `crypto_runtime/` …) **داخل جذر المشروع** — يُرجَّح أنّه
بقايا فكّ ضغط سابق. **لم يُلمس ولم يُحذف** — مرصود لقرار المالك فقط.
