# دستور QUANT_NQ

**الحالة:** نافذ  
**تاريخ النسخة:** 2026-08-27  
**Build ID:** `QUANT_NQ_COMPLETE_FULL`  
**الإصدار:** 1.0 من دستور الإصدار المؤسسي

هذا الملف هو المرجع الأعلى لأي مطور أو نموذج أو مدقق. إذا تعارضت ورقة قديمة مع هذا الملف، فالقديمة تُصنّف أرشيفًا غير نافذ ولا تُستخدم للتشغيل.

---

## 1. سلطة المالك وعدم التخمين

- قرار المالك هو المرجع عند تعارض عقدين.
- لا يختار النظام Build أو رقمًا أو استثناءً من تلقاء نفسه.
- لا يتحول التحذير إلى PASS بإخفائه.
- لا يتحول فشل الفحص إلى تعديل عشوائي في الذرات.
- كل استثناء يجب أن يكون مسجلاً باسمه وسببه ونطاقه.
- أي تعارض غير محسوم يجعل Release محجوبًا.

## 2. طبقات النظام

```text
Build Registry
      ↓
Core + Contracts
      ↓
Shared
      ↓
Forex / Crypto
      ↓
Governance
      ↓
Release Gate
```

كل طبقة لها مسؤولية واحدة:

| الطبقة | المسؤولية |
|---|---|
| Build Registry | اكتشاف المكونات وتصنيفها وإظهار التعارضات |
| Core | الحاوية، دورة الحياة، الناقل، الصحة، اللقطات |
| Shared | عقود وخدمات محايدة مشتركة |
| Forex/Crypto | منطق النطاق والذرّات التابعة له |
| Governance | فحص وسياسة وتدقيق وعرض، لا تصبح Domain تداول |
| Release Gate | تقرير جاهزية الإصدار، وليس إقلاع Core |

## 3. دستور Core

Core عامة وجاهلة بالنطاق. لا تعتمد على:

```text
atoms implementation
atoms_crypto implementation
governance implementation
transport implementation كمنطق نطاق
```

Core تستخدم العقود العامة فقط:

```text
AtomBase
AtomContext
AtomManifest
EventBus
Registry
HealthManager
SnapshotEngine
```

Core لا تعرف اسم أو رقم ذرة بعينها، ولا تعرف استراتيجية أو وسيطًا أو سوقًا. سياسات النطاق تُحقن من خارجها عبر adapter عام.

ختم Core الحالي:

```text
Core version = 1.27.0
CORE.lock = valid
```

## 4. عقد الذرة

كل ذرة تلتزم بـ:

```python
async def initialize(context)
async def start()
async def stop()
async def shutdown()
```

والدوال الاختيارية:

```python
async def health_check()
async def snapshot()
async def restore(state)
```

التسلسل:

```text
DISCOVERED
  ↓
VALIDATED
  ↓
REGISTERED
  ↓
INITIALIZING
  ↓
INITIALIZED
  ↓
STARTING
  ↓
RUNNING
```

الإيقاف:

```text
RUNNING → STOPPING → STOPPED → SHUTDOWN → UNLOADED
```

إعادة التشغيل تستخدم:

```text
STOP → START
```

ولا تستعمل `SHUTDOWN` في Restart القابل للعكس.

## 8. الأحداث

EventBus هو قناة التخاطب الوحيدة بين الذرات.

قواعد الحدث:

- اسم نقطي واضح.
- حمولة JSON قابلة للتسلسل.
- كل مشترك معزول عن غيره.
- لكل معالج مهلة.
- الأثر والوقت والمصدر واضحون.
- الحدث الذي ينتهي بـ`.state` أو `.synced` أو `.snapshot` قابل لإعادة الحالة.
- أحداث الأمر لا تُعاد ولا تُخزّن كي لا يتكرر التنفيذ.
- `asset.portfolio.owner_intent.state` هو حدث الحالة الرسمي الجديد لـ519.
- الحدث القديم `asset.portfolio.owner_intent` محفوظ للتوافق فقط.

## 10. الإقلاع

إقلاع Core منفصل عن إقلاع الذرات:

```text
Core services
    ↓
Bootloader للذرّات غير التنفيذية
    ↓
Core جاهزة
    ↓
Execution Safety
    ↓
Bootloader لأهداف التنفيذ
```

فشل ذرة لا يعني فشل Core. و`manual` لا يعني أن Core فشلت.

Core يمكنها الإقلاع مع جذر ذرات فارغ:

```text
Zero-atom Core = RC 0
```

## 12. السلامة المالية

- لا حساب حقيقي داخل الحزمة.
- لا أسرار داخل ZIP.
- لا تنفيذ مالي بسبب نجاح فحص بنيوي وحده.
- Execution Safety لا تُحذف ولا تُخفف.
- قاطع الطوارئ أعلى من أي زر آخر.
- فتح بوابة لا يلغي Halt سابقًا.
- لا يُقبل أمر بلا هوية وحساب ورمز ومرجع وحماية مناسبة.
