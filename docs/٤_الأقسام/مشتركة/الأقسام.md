# خريطة الأقسام والذرّات — QUANT_NQ

**هذا الملف هو الفهرس الواحد للوصول إلى كل ذرة.** مسار القرص قد يكون عميقًا، والهوية هي Atom ID لا اسم المجلد.

## الوضع الحالي

- فوركس داخل الجذر `atoms/`: **233** مانيفست.
- كريبتو داخل الجذر `atoms_crypto/`: **76** مانيفست.
- حوكمة/حدود تحكم: **2** ذرات ضمن العرض المفصول.
- Shared: **29** ملفًا.

## القاعدة

- لا تنقل الذرة ولا تعيد ترقيمها للوصول إليها.
- استخدم `BuildRegistry.find_atom(id)` أو جدول هذا الملف.
- `startup_mode` قرار تشغيل الذرة، وليس تعريفًا للقسم.
- ملفات Governance لا تدخل كمنطق Forex أو Crypto.
