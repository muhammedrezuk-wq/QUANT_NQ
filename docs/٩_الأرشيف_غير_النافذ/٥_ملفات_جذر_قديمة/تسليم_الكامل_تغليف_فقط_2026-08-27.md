# التسليم الكامل — كل الذرات والطبقات في ZIP واحد

## المحتوى

```text
atoms/        233 ذرة فوركس
atoms_crypto/ 76 ذرة كريبتو
```

مسار `atoms_crypto/` يحتوي:

- 1001 مدير كون الأصول.
- 1002 تغذية السوق.
- 74 ذرة كاملة من مصدر ASMAR، معاد ترقيمها إلى IDs تبدأ من 2000.
- الحواس والبيانات والميكروبنية والتخزين والقياس والأخبار والحوكمة والنقل
  والاختبارات.

## الحالة التشغيلية

- كل الذرات موجودة فعليًا داخل نفس ZIP.
- كل IDs الخاصة بالكريبتو فوق 1000.
- لا يوجد تشغيل تلقائي أثناء التغليف.
- `1001` و`1002` هما المسار التلقائي الحالي.
- ذرات المصدر الكامل مضبوطة `manual` حتى لا تبدأ طبقة غير مختبرة تلقائيًا.
- لا يتم حذفها أو إخفاؤها أو تركها في مرجع خارجي.

## التحقق

```text
Forex atoms: 233
Crypto atoms: 76
Crypto IDs: unique and >= 1000
Archive: tested
Services started during packaging: none
```

بعد فك الضغط، فحص الملفات فقط:

```bash
python scripts/verify_unified.py
```
