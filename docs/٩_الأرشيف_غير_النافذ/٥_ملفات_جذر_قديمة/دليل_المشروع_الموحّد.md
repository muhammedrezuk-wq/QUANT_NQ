# QUANT_NQ — التسليم الكامل

هذه النسخة تحتوي مشروعًا واحدًا كاملًا داخل ZIP واحد:

```text
atoms/        = الفوركس / MT5 / cTrader — 233 ذرة
atoms_crypto/ = الكريبتو الكامل — 76 ذرة مرقّمة فوق 1000
```

## محتوى الكريبتو

- `1001` مدير كون الأصول.
- `1002` تغذية السوق Phase A.
- 74 ذرة كاملة من مصدر ASMAR، معاد ترقيمها إلى `2000+`.
- الحواس، التخزين، القياس، الأخبار، الحوكمة، والنقل محفوظة داخل نفس مسار
  `atoms_crypto/`.
- كل ذرات المصدر الكامل في هذه النسخة مضبوطة `startup_mode: manual` حتى لا
  يتم تشغيل طبقات لم تعتمد عقودها التشغيلية بعد.
- `1001` و`1002` هما نقطة التشغيل التلقائية الوحيدة لمسار الكريبتو.

## ما تم حلّه في التغليف

- لا يوجد مجلد Crypto مرجعي ناقص أو مخفي خارج ZIP.
- لا يوجد رقم Crypto خاص أقل من 1000.
- لا توجد أسماء IDs متصادمة داخل مسار Crypto.
- لا يتم تشغيل ذرات المصدر الكامل تلقائيًا.
- المصدر الكامل محفوظ كملفات حقيقية داخل `atoms_crypto/` وليس كمرجع ناقص.
- الفوركس والكريبتو لهما إعدادات وناقلات ومخازن منفصلة.

## التشغيل التلقائي

`غرفة القيادة.bat` يشغّل Phase A تلقائيًا فقط. الذرات الكاملة محفوظة وجاهزة
للتفعيل بعد اختبار عقودها، لكنها لا تعمل في الخلفية من تلقاء نفسها.

للتشغيل اليدوي الكامل:

```bash
python scripts/prepare_unified.py
python scripts/verify_unified.py
python scripts/launch_unified.py
```

أو شغّل المكونات منفصلة:

```bash
python scripts/run_forex.py
python scripts/run_crypto.py
python scripts/run_governance.py --market forex --port 8092
python scripts/run_governance.py --market crypto --port 8093
python governance/unified_hub.py
```

المنافذ الداخلية:

```text
Forex Core       8010
Crypto Core      8020
Forex Governance 8092 (داخلي)
Crypto Governance 8093 (داخلي)
```

العنوان الوحيد الظاهر للمستخدم:

```text
Unified Hub      http://127.0.0.1:8090
```

زر `فوركس ⇄ كريبتو` يبدّل المسار داخل نفس التطبيق ومن دون تغيير عنوان الصفحة
أو إعادة تحميلها.

## التحقق بدون تشغيل

```bash
python scripts/verify_unified.py
```

يجب أن يظهر:

```text
Forex atoms: 233
Crypto atoms: 76
Core seal: OK
Unified release verification: OK
```

لا توجد أي عملية تعمل عند فك الضغط. هذا الملف يشرح المحتوى فقط.
