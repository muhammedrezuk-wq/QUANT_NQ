```sql
-- 601 — كل ما يفعله emergency.halt

       done_at=? WHERE status='PENDING' AND account_id=?
```

**والمستمعون للحدث (ثمانية اليوم بالمانيفستات — أبرزهم):**

```
575   _halted_accounts[account] = reason        ← راية — والخروج يمرّ رغمها (أدناه)
550   self._rehydrated = True                   ← راية فقط

```

**(تحديث ٢٥-٠٨: `575 v2.2.0` قلب سطره — الإيقاف لم يعد يحجب أوامر الخروج.**
`CLOSE` / `CLOSE_PARTIAL` / `MODIFY_SL` **تمرّ أثناء الطوارئ** (`atom.py:224-232`)، لأنّ حجبها
كان انقلاب أمان مقيسًا: المالك يوقف النظام فيفقد القدرة على الخروج من السوق.
**فذرّات الإدارة تظلّ ترسل الإغلاق والحماية أثناء الإيقاف — المراكز لا تبقى بلا إدارة.)**

**⇒ لكن ما من ذرّة تُصدر أمر إغلاق بسبب الطوارئ نفسها** — الحدث لا يولّد `CLOSE`.

**بلغة المال:** لو انفتحت مراكز ثمّ ضُربت الطوارئ، **لا يُطلق الحدثُ نفسُه إغلاقها** —
يغلقها الستوب عند الوسيط، أو يد المالك، أو أمر إدارةٍ يمرّ رغم الإيقاف.
**«إيقاف» تعني «توقّف عن الدخول» لا «اخرج» — والخروج بابه مفتوح.**
