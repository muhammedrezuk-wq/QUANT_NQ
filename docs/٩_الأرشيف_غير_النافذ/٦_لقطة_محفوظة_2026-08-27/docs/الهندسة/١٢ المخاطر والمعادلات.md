# ١٠ · المخاطر — ثلاث طبقات

```
١ · التحجيم   capacity = R_B ÷ (price × stop_frac × vpu)
              ⇒ ضربة وقف كاملة تكلّف R_B بالضبط، لا أكثر

٢ · سقف الحجم gross_cap = min(max_target, 2·R_B÷unit, R_B÷كلفة_التحوّط)
              ⇒ الطرف الثالث يمنع أن تأكل كلفة التحوّط الميزانيّة

٣ · العدّاد   u = التعرّض للخسارة ÷ R_B
              u ≥ 0.95  →  WARNING  (تحوّط، لا زيادة)
              u ≥ 1.00  →  FROZEN   (لا زيادة إطلاقًا)
```

**وميزانيّة كل أصل مستقلّة.** خسارة أصل لا تمسّ ميزانيّة أصل آخر، ومخاطر الحساب أ
توقف أ وحده.

```
K = max(0, G − الكلف المحقّقة − X)     الربح المُبقى — مخزون دائم يوسّع المجال

```
