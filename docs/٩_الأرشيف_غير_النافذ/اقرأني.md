# الأرشيف غير النافذ

هذا المجلد يحفظ الأوراق والتقارير القديمة كما كانت قبل توحيد الوثائق.

```text
الحالة = LEGACY / NON-OPERATIVE
```

لا يجوز:

- أخذ قرار تشغيل من ملف داخله.
- اعتبار أرقامه الحالية مصدر الحقيقة.
- نسخ مسار قديم إلى الكود.
- استخدامه بدل `docs/٠_الدستور` أو بقية الوثائق النافذة.

المراجع النافذة الوحيدة هي الملفات الجامعة مباشرة تحت:

```text
docs/٠_الدستور
docs/١_الهندسة
docs/٢_المسارات
docs/٣_الأحداث
docs/٤_الأقسام
docs/٥_السياق
docs/٦_التدقيق
```

وجود ملف في الأرشيف لا يعني أنه صحيح حاليًا؛ يعني فقط أنه محفوظ للتاريخ والمقارنة.
