# ٥ · الممنوع والمسموح

## 🔴 ممنوع منعًا مطلقًا

| الممنوع | السبب |
|---|---|
| **حذف أي ملفّ** | الحذف النهائيّ بيد المالك وحده. البديل: **الأرشفة** |
| **فتح النواة بلا إذن جديد** | النواة مختومة؛ الإذن لا يُورَّث من مرّة لأخرى |
| **تنفيذ بلا ختم `NQ`** | الموافقة اللفظيّة ليست ختمًا |
| **المساس بحارس الأوامر في الناقل** | إعادة أمر تنفيذ = **صفقة مزدوجة على حساب حقيقيّ** |
| **تجميع الإكسبرت أو نشره** | التجميع والنشر بيد المالك حصرًا؛ يُصلَح المصدر فقط |
| **إعادة ربط قسم بحدث الشمعة** | الوحدة تِكّة؛ المراكم التِكّي `O(1)` هو البديل المعتمد |
| **فرض إعادة تشغيل على جسر بلا أذى مقيس** | حكم المالك 2026-08-25 (ناقضًا حكم 21-08): كل الجسور تتحمّل التحميل الساخن؛ لا تحميل بارد إلا بأذى مقيس بالرقم — 618 تبدّلت ساخنة بلا انقطاع مقيسًا |
| **صياغة لينكس أو Bash** | البيئة ويندوز/PowerShell، حتى في التحليل الداخليّ |
| **الشغل في الخلفيّة** | كل شيء أماميّ ظاهر أمام المالك |
| **النسخ من طقم الذرّات القديم** | `Desktop\ذرات` أفكار فقط — لا يُنسخ منه سطر |
| **حماية أو نسخ احتياطيّ تلقائيّ** | المالك يحمي بنفسه على وسيط خارج المشروع |
| **اتّصال شبكيّ مباشر داخل ذرّة** | الشبكة عبر بوّابة ذرّيّة موثّقة فقط |
| **أسرار داخل الذرّة** | كلمات السرّ والمفاتيح من نظام الإعدادات — النواة والذرّة جاهلتان عنها |
| **الترقيع** | الحلّ من الجذر دائمًا. رقعة فوق خلل = خلل فوق خلل |
| **لمس ما يشتغل** | ولا إعادة بناء بلا سبب |

## 🟢 مسموح ومطلوب

| المسموح | الشرط |
|---|---|
| **الاعتراض على طلب المالك** | **واجب لا خيار** حين يصادم الطلبُ رؤيتَه — مرّة واحدة قبل التنفيذ، ثمّ يُنفَّذ ما يقرّره |
| **قول «لا أعرف» و«أخطأت»** | في وقتهما، لا اعترافًا متأخّرًا بعد أيام شغل |
| **الأرشفة** | بديل الحذف الدائم |
| **رفع طبقة فوق الذرّات** | التوحيد يكون **طبقة فوق**، لا على حساب العزل ولا الدقّة |
| **الترمنال الخام** | مقبول ومفضَّل — يُوثَق به لأنّه خام لا يُصقَل |

## ⚖️ الاعتراض — الحدّ بين «لا» التي تحمي و«لا» التي تدمّر

```
الطلب يصادم رؤية المالك        →  يُعترَض. هذه «لا» تحميه.
المنفّذ يرى رأيه أصحّ ويفرضه   →  ممنوع. هذه «لا» التي كسرت المشروع ٧٣ مرّة.
```

**الاعتراض مربوط برؤية المالك دائمًا، لا برأي المنفّذ.**
وإذا كرّر المالك طلبه بعد الاعتراض، **فقراره نافذ ويُنفَّذ كاملًا.**
