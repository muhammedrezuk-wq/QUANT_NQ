# بوّابات التنفيذ وطريق الوسيط

## ز · بوّابات قبل السوق

```
586  بوّابة الرموز      حلّ اسم الرمز عند هذا الوسيط — على execution.order.requested
585  حارس الهامش        الهامش المتاح + احتياطيّ — يحكم على الأمر المحلول قبل البناء
551  باني الأمر        يبني OPEN / CLOSE_PARTIAL / MODIFY — execution.order.built
584  شرعيّة الستوب      مسافة الوقف وعائدها — execution.order.legal
552  مدقّق الأمر        ← البوّابة الوحيدة التي تُصدر القرار النهائيّ
```

**فحوص `552` بالترتيب:**

```
عقد الأمر     action · symbol · side · volume > 0 · reference_price > 0
              ثمّ stop_loss و take_profit وترتيب المستويات
              (والزوج المحايد معفى صراحةً من الوقف والهدف)
الهويّة       account · broker · symbol — وإلّا MISSING_ACCOUNT_BROKER_OR_SYMBOL
الرقم السحريّ  magic > 0
القائمة البيضاء  fail-closed: بلا قائمة = منع تام
السبريد       max_spread_points
الطوارئ       halted عامًّا أو للحساب
سلطة الأب     دخولٌ اتّجاهيّ يحمل قرار أبيه أو سلطة مالك موثّقة
حكم الهامش    حكم 585 لنفس الطلب — MARGIN_VERDICT_MISSING / _REJECTED
اللقطة        صلاحيّة لقطة 583 — SNAPSHOT_NOT_USABLE
الساعة        تزامن الساعة — CLOCK_NOT_SYNCED
المطابقة      مطابقة 520 = MATCH — RECONCILIATION_NOT_MATCHED
المرجع        صحّة المرجع 521 — REFERENCE_NOT_USABLE
التعرّض       صلاحيّة تعرّض 508 — EXPOSURE_STATE_NOT_USABLE
```

## ح · إلى الوسيط

```
601  كاتب الجسر  →  صفّ في جدول commands بحالة PENDING
                     مع: request_id · action · symbol · side · volume
                          price · stop_loss · take_profit · magic
                          account_id · project_build_id · params_json

الإكسبرت QUANT_NQ.mq5  →  يلتقط الصفّ ويأمر الوسيط
```

**حرّاس `601`:** الحساب يطابق ما يعلنه الجسر · الرقم السحريّ يطابق · `request_id`
موجود · الفعل من قائمة مغلقة · **منع تكرار ذرّيّ** بـ`BEGIN IMMEDIATE`.

**حرّاس الإكسبرت:** أمر أقدم من ثانيتين يُختم `EXPIRED` ولا يُنفَّذ · `OPEN` بلا وقف
يُرفض · مطالبة ذرّيّة تمنع تنفيذًا مزدوجًا · تحقّق من ملكيّة الحساب وهويّة البناء ·
**محاولة واحدة بلا إعادة** فلا يتحوّل الرفض إلى وابل أوامر.
