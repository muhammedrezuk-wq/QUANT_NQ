# ٦ · نموذج الوقت

```
جوّا النظام        UTC واحد
برّا النظام        تحويل لأيّ منطقة — للعرض فقط

وقت السوق          من التِكّة · مطبَّع UTC · مفحوص عند الدخول
                   وبديله الآمن وقت الاستلام لو أرسل الوسيط قيمة فاسدة

«الآن»             ساعتنا المصحَّحة بـNTP — للقِدَم والجدولة
                   ⛔ ممنوع خلط وقت السوق بوقت «الآن»

حدود المحترفين     اليوم = إغلاق نيويورك 17:00 ET
                   الأسبوع = جمعة نيويورك
                   الجلسات قياسيّة — والشموع والريست عليها

الترتيب            عند خشونة الساعة يُستعمل event_id
```

**وثلاث ذرّات فقط تملك الساعة: `3` · `806` · `608`.**
