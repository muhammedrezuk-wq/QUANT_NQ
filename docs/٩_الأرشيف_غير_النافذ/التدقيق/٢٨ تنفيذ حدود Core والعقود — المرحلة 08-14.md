## 2. 08 — Core Boundary

### التنفيذ

تم تحويل `/api/events` داخل `core/api/app.py` إلى ingress عام:

```text
Core API
    ↓
control_event_publisher injected by outer adapter
    ↓
Domain policy outside Core
```

عند غياب adapter:

```text
control adapter unavailable → 503 / fail closed
```

```text
governance/control_adapter.py
```

وأصبح الغلافان يحددان النطاق خارجيًا:

```text
run_forex.py  → QUANT_CORE_DOMAIN=forex
run_crypto.py → QUANT_CORE_DOMAIN=crypto
```

### التحقق

```text

1001 داخل core/api/app.py = 0
Python compile = PASS
Core seal after reseal = PASS
```

### الحكم

```text
Core API domain vocabulary = removed
Domain policy location = external adapter
```

ملاحظة: بقيت إشارات Crypto التاريخية في changelog داخل `core/__version__.py` كأثر تاريخي غير تنفيذي، ولم تعد جزءًا من API التنفيذية.

## 11. المتبقي قبل HotReload

```text

توحيد بقية Governance checkers التي ما زالت تستخدم مسارات Atom مباشرة
الفصل النهائي لموضع execution preflight عن Core Boot

```

خصوصًا:

```text
F-CORE-002 ما زال جزئيًا:
run_core يعرف execution policy قبل run()/Bootloader.
```

تمت معالجة الاكتشاف والمسارات، لكن لم يتم بعد إعادة بناء مرحلتي Core Boot وAtom Boot حول بوابة تنفيذ مستقلة.
