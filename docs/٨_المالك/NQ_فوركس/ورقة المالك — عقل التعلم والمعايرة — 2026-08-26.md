# ورقة المالك — عقل التعلم والمعايرة (AI مدير تعلّم ومعايرة)
**(وصلت بمحادثة ٢٦-٠٨ وخُتمت بكلمته: «هاد بدي ياه» · جوهرها محفوظ بأمانة، وملاحظة التنفيذ بالذيل)**

## الفكرة
ليس AI مراقبًا فقط — بل **مدير تعلّم ومعايرة** يعيش داخل النظام، مع **فصل صريح جدًا بين المشاهدة والتنفيذ**. مثل متداول متدرّب + مهندس معايرة يشتغل يوميًّا:
```text
السوق الحقيقي ← النظام يحلل ← AI يراقب كل شيء ← يشاهد النتائج ← يراجع السجل
← يكتشف أين أخطأ النظام ← يختبر ماذا كان يجب أن يتغير ← يتعلم
← يقترح/ينفذ معايرة ← يراقب النتيجة ← يتكرر
```
**والمالك صاحب المفتاح.**

## المفاتيح الثلاثة (كل واحدة مستقلة)
| الوضع | ماذا يفعل AI؟ |
|---|---|
| **WATCH** | يشاهد ويتعلم فقط — يراقب السوق والنظام، يحلل النتائج، يتعلم من السجل، يكتشف الأخطاء، يبني تقييمه — **ولا يغيّر شيئًا** |
| **CALIBRATE** | يتعلم ويعاير ضمن الصلاحيات المحددة له — لا «AI قرر أن 73 أفضل من 68» بل: **المشكلة ← فرضية ← تعديل ← اختبار ← نتيجة ← مقارنة مع السابق ← قبول/رفض ← سجل كامل** |
| **EXECUTE** | بوابة التداول — منفصلة تمامًا |
ويمكن: `WATCH=ON · CALIBRATE=ON · EXECUTE=OFF`.

## بيئة التدريب
الحساب التجريبي = بيئة تعلم حقيقية بدورة كاملة (تحليل←قرار←تداول←نتيجة←سجل←تحليل الخطأ←معايرة←إعادة اختبار). في البداية قد يخبص — وليس مشكلة إذا: الحساب Demo · الخسارة محدودة · كل شيء مسجل · المعايرة قابلة للرجوع · لا يخرج من صلاحياته · **لا ينتقل للحساب الحقيقي تلقائيًّا**.

## التعلم المفيد (لا «تعلم تداول» غامض)
يتعلم **من سلوك النظام نفسه**: «عندما يكون السوق سريعًا جدًّا، محلل X يصبح أقل موثوقية» ← أدلة من مئات الحالات ← «ظهرت 147 مرة ونسبة الخطأ ارتفعت بهذا المقدار» ← عندها يدخل المعايرة.

## لوحة AI STATUS
بدل فتح 151/152/.../166 يوميًّا والسؤال «شو أغير اليوم؟» — لوحة تقول: حالة السوق والنظام وجودة الدليل وحال كل محلل، و«معايرة مطلوبة: نعم — السبب — الإجراء المقترح — **الحالة: بانتظار السماح**» والمالك يقرر (أو تجري الدورة إن كان CALIBRATE مفعّلًا ضمن الحدود).

## الحدود (لا حرية «عدّل ما تريد» حتى على Demo)
```text
AI: مراقبة ✓ · تحليل ✓ · تعلم ✓ · تشخيص ✓ · Backtest ✓ · معايرة ✓
    Risk Dial ✗ · R_B ✗ · حدود الحساب ✗ · Safety ✗ · Governance ✗
```
وكل تغيير: **مسجل + قابل للمقارنة + قابل للرجوع.**

## الخلاصة (بنصّه)
> AI يشغّل دورة التعلم والمعايرة اليومية للنظام، يتعلم من التداول والنتائج والسجل، يكتشف أين النظام جيد وأين يخرب، ويطوّر عياراته تدريجيًّا — **لكن المالك يملك المفاتيح**: هل يشاهد فقط، هل يُسمح له بالمعايرة، وهل يُسمح للنظام بالتنفيذ.
