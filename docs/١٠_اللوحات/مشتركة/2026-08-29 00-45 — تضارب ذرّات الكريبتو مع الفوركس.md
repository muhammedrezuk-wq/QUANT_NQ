## ٢) السبب الجذريّ — مقاس بالكود

`governance/ui/src/core/transport.ts` — دالّة `connectWs` تتناوب بين **مسارَي
اتصال** عند كل محاولة:

```ts
const viaRelay = attempt % 2 === 0
//  زوجيّ  → RELAY_WS = /gov/ws/core   (عبر الهبّ · يقرأ كوكي QUANT_MARKET ✅)
//  فرديّ  → CORE_WS  = ws://host:8010/ws/events   ← 🔴 مثبّت على الفوركس دائمًا
```

**`CORE_WS` كان ثابتًا على المنفذ 8010 (نواة الفوركس)** — فكل إعادة اتصال
بمحاولة فرديّة تربط لوحة الكريبتو بنواة الفوركس، وتضخّ 226 ذرّة فوركس فوق
ذرّات الكريبتو الـ33. **التناوب هو سبب «مرّة هيك ومرّة هيك».**

**ما كان سليمًا (لا يُعاد فحصه):**
- نبض REST كل 4 ثوانٍ (`/gov/atoms`) يمرّ بالهبّ ⇒ **سوقه صحيح دائمًا**
- محرّك اللوحة يعيد التشغيل عند التبديل (`useEffect … [marketInfo?.market]`) ⇒ سليم
- الهبّ نفسه يقرأ الكوكي صحيحًا (`_market()` في `unified_hub.py`) ⇒ سليم

**فالخلل نقطة واحدة: منفذ المسار الاحتياطيّ المباشر.**

## ٣) الإصلاح

```diff
- const CORE_WS = `ws://${_hostname}:8010/ws/events`     // فوركس دائمًا
+ const CORE_PORTS: Record<string, number> = { forex: 8010, crypto: 8020 }
+ const _coreWs = (): string => {
+   const m = /(?:^|;\s*)QUANT_MARKET=(forex|crypto)/.exec(document.cookie)
+   return `ws://${_hostname}:${CORE_PORTS[m ? m[1] : 'forex'] ?? 8010}/ws/events`
+ }
```
**ويُستدعى عند كل محاولة اتصال لا مرّة واحدة** — كي يتبع التبديل فورًا:
```diff
- next = new WebSocket(CORE_WS, …)
+ const coreUrl = _coreWs()
+ next = new WebSocket(coreUrl, …)
```

**المسار الاحتياطيّ بقي كما هو وظيفيًّا** (لم يُحذف) — صار فقط يتبع السوق.
