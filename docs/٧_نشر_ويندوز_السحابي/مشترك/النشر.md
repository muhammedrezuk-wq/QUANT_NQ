# نشر QUANT_NQ على Windows Cloud للتداول الحقيقي

## وضع هذه الوثيقة

هذه وصفة نشر وتشغيل على جهاز Windows سحابي. لا تحتوي أسرارًا ولا تطلب إرسال كلمة مرور أو مفتاح في المحادثة.

وجود الحزمة لا يعني أن حساب الوسيط صار متصلًا. اعتماد التداول الحقيقي لا يتم إلا بعد فحص الجهاز والجسر والحساب الفعلي.

## المتطلبات

- Windows Server 2022 x64 أو إصدار يحدده المالك.
- Python 3.12 أو أحدث ضمن المجال المدعوم.
- MT5 أو cTrader مثبت على **نفس جهاز الكلاود** حسب الجسر المختار.
- اتصال الشبكة إلى الوسيط، مع جدار ناري يمنع المنافذ غير الضرورية.
- تخزين دائم للسجلات واللقطات.
- دخول RDP آمن أو شبكة خاصة مثل Tailscale؛ لا تفتح Core مباشرة للإنترنت.

## تجهيز الحزمة

1. فك الضغط في مجلد جديد، مثل:

```text
C:\\Quant\\QUANT_NQ
```

2. شغّل:

```text
أزرار التشغيل\\تهيئة المشروع الموحد.bat
```

هذا ينشئ بيئة Python ويثبت الاعتماديات ويجهز روابط `forex_runtime` و`crypto_runtime` المطلوبة للتشغيل.

3. شغّل قبل أي حساب:

```text
أزرار التشغيل\\٥_فحص_المشروع.bat
```

والنتيجة المطلوبة:

```text
Registry PASS
Core seal PASS
Validator errors = 0
```

## ربط الجسر

- لا تنسخ كلمة مرور أو مفتاحًا إلى ملفات المشروع.
- أنشئ خزنة الأسرار من صفحة الأمان على جهاز Windows نفسه.
- شغّل فحص جسر MT5 أو فحص cTrader بحسب المنصة.
- تحقّق يدويًا من:
  - الوسيط والـServer.
  - رقم الحساب المقروء.
  - السماح بالتداول.
  - السماح للإكسبرت.
  - الرموز المطابقة لرموز الوسيط.
  - تطابق الحساب داخل كل أمر.

إذا فشل أي بند، تبقى بوابة التنفيذ مقفولة.

## تشغيل اللوحة

```text
أزرار التشغيل\\غرفة القيادة الموحدة.bat
```

الدخول المحلي من RDP:

```text
http://127.0.0.1:8090
```

الوصول من متصفح خارجي يحتاج إعدادًا شبكيًا مقصودًا ومفتاح `QUANT_GOV_API_KEY`، ويفضل أن يكون خلف شبكة خاصة. لا تفتح المنافذ الداخلية 8010 و8020 و8092 و8093 للعامة.

## ترتيب الاعتماد للتداول الحقيقي

```text
إقلاع Core
  ↓
فحص Registry وCore.lock
  ↓
فحص الجسر قراءة فقط
  ↓
مطابقة الحساب والوسيط والرموز
  ↓
اختبار الاستعادة وإعادة التشغيل
  ↓
فحص قاطع الأمان
  ↓
اختبار بيانات حيّة بلا أمر
  ↓
موافقة المالك على بوابة التنفيذ
```

`execution_auto_started` لا يعني أن الحساب صار معتمدًا، ووجود مصدر MT5 لا يثبت اتصال الوسيط.

## الضغط والاستقرار

قبل فتح البوابة على الحساب الحقيقي:

- Smoke لمدة 10 دقائق.
- Burst على بيانات اصطناعية، لا على أوامر الحساب.
- Soak لمدة 24 ساعة.
- عشر دورات إيقاف وتشغيل نظيف.
- فصل MT5 والإنترنت ثم التحقق من العودة والمطابقة.
- إعادة تشغيل Windows والتحقق من اللقطات والحالة.
- مراقبة نمو الذاكرة وسقوط الأحداث والسجلات.

أي نتيجة غير واضحة تصير `BLOCKED`، ولا يتم فتح البوابة بالتخمين.

## فحوص ما بعد النشر

```text
أزرار التشغيل\\٤_المدقق_الشامل.bat
أزرار التشغيل\\٥_فحص_المشروع.bat
أزرار التشغيل\\٦_فحص_الأحداث.bat
أزرار التشغيل\\٧_الاختبارات_الكاملة.bat
```

النتيجة النافذة تُسجّل مع مسار الجهاز ووقت الفحص. الاختبارات المحلية لا تغني عن إثبات الجسر الفعلي.
